Установка, настройка и первый тест

Три короткие страницы, чтобы установить Git и настроить среду, собрать минимальный проект и запустить модульные тесты на Windows или Linux.

ГлавнаяWindowsLinuxПростой проект

С чего начать

CUnit — библиотека для написания и запуска модульных тестов на C. В примере используется интерфейс CUnit/Basic.h, который выводит результат тестов в терминал.

1. WindowsУстановка MSYS2, Git, GCC, Make и CUnit; проверка инструментов.2. LinuxУстановка Git и пакетов в Debian/Ubuntu, проверка инструментов.3. Первый проектИсходники, Makefile, тест и ожидаемый результат.

Что получите

  • Программу main, вызывающую функцию из func.c.
  • Набор тестов test_main, который проверяет эту функцию через CUnit.
  • Git для клонирования учебного репозитория и сохранения изменений.
  • Команды make, make test и make clean.
Рекомендуемый порядок: установите инструменты для своей ОС, скачайте папку example из комплекта, перейдите в неё в терминале и выполните make test.
