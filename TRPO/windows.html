CUnit на Windows

Устанавливаем Git, GCC, Make и CUnit через MSYS2. Все команды ниже нужно вводить в терминале MSYS2 UCRT64, а не в обычном PowerShell.

ГлавнаяWindowsLinuxПростой проект

Шаг 1. Установить MSYS2

  1. Откройте официальный сайт MSYS2 и скачайте установщик.
  2. Установите MSYS2. Путь по умолчанию (обычно C:\msys64) лучше оставить без изменений.
  3. Откройте меню «Пуск» и запустите MSYS2 UCRT64.
Важно: используйте одно и то же окружение UCRT64 для установки пакетов, компиляции и запуска тестов. Не смешивайте библиотеки из MSYS, MINGW64 и UCRT64.

Шаг 2. Установить Git, компилятор, Make и CUnit

В окне MSYS2 UCRT64 выполните:

pacman -Syu

Если терминал просит закрыть окно после обновления, закройте его, снова откройте MSYS2 UCRT64 и повторите обновление при необходимости. Затем установите инструменты:

pacman -S --needed git base-devel mingw-w64-ucrt-x86_64-toolchain mingw-w64-ucrt-x86_64-cunit

Подтвердите установку, когда пакетный менеджер спросит об этом. Пакет git устанавливает систему контроля версий, а пакет CUnit содержит заголовки, библиотеку для линковки и DLL для выполнения программы. В том же терминале MSYS2 UCRT64 можно выполнять команды Git, клонировать учебный репозиторий и отправлять изменения.

Справка: Git в MSYS2, управление пакетами MSYS2, состав пакета CUnit.

Шаг 3. Проверить инструменты

В том же окне выполните команды по очереди:

git --version
gcc --version
make --version
pacman -Q mingw-w64-ucrt-x86_64-cunit

Каждая команда должна вывести версию или сведения об установленном пакете. Убедитесь, что первая команда запускает GCC из окружения MSYS2, а не другой компилятор из Windows.

Шаг 4. Собрать и запустить пример

  1. Скачайте архив комплекта, распакуйте его, найдите папку example.
  2. В проводнике перейдите в эту папку, щёлкните правой кнопкой мыши и выберите открытие терминала, либо используйте cd в MSYS2. Например, для папки в Downloads:
cd ~/Downloads/cunit_guide/example

Путь может отличаться в зависимости от того, куда вы распаковали архив. Затем выполните:

make
./main
make test
make clean
Ожидаемый результат тестирования: в выводе CUnit указано, что все тесты пройдены, а число ошибок равно нулю. Программа main печатает 2 + 3 = 5.

Если возникла ошибка

Сообщение / симптомЧто проверить
git: command not foundВ MSYS2 UCRT64 выполните pacman -S --needed git, затем проверьте git --version.
gcc: command not foundОткройте именно MSYS2 UCRT64 и проверьте установку mingw-w64-ucrt-x86_64-toolchain.
make: command not foundУстановите пакет base-devel через pacman.
CUnit/Basic.h: No such file or directoryУстановите пакет CUnit именно для UCRT64.
cannot find -lcunitПроверьте, что вы работаете в UCRT64, и повторите установку пакета.
Не удаётся запустить DLLЗапускайте программу из MSYS2 UCRT64, где каталог /ucrt64/bin находится в PATH.
