CUnit на Linux

Ниже — инструкции для Debian и Ubuntu. Устанавливаем Git, компилятор C, утилиту Make и файлы разработки CUnit.

ГлавнаяWindowsLinuxПростой проект

Шаг 1. Обновить список пакетов

Откройте терминал и выполните:

sudo apt update

Введите пароль пользователя, если система его запросит.

Шаг 2. Установить Git, компилятор, Make и CUnit

sudo apt install git build-essential make libcunit1-dev

git нужен для работы с репозиторием задания, клонирования проекта и фиксации изменений. build-essential включает основные инструменты сборки, make выполняет правила из Makefile, а libcunit1-dev устанавливает заголовки и файлы разработки CUnit.

Официальная документация Git: установка Git. Пакет CUnit может находиться в компоненте universe Ubuntu. Если APT не находит пакет, проверьте, что нужные репозитории подключены.

Шаг 3. Проверить установку

git --version
gcc --version
make --version
dpkg -s libcunit1-dev | grep -E '^(Status|Version):'

Ожидается, что компилятор и Make выведут свои версии, а статус пакета будет install ok installed.

Шаг 4. Собрать и запустить пример

  1. Распакуйте архив комплекта в удобную папку.
  2. Перейдите в каталог примера. Например, если он находится в каталоге Downloads:
cd ~/Downloads/cunit_guide/example

Используйте фактический путь к распакованной папке. Далее выполните:

make
./main
make test
make clean
Программа main должна напечатать 2 + 3 = 5, а CUnit — сообщить, что все проверки пройдены без ошибок.

Если возникла ошибка

Сообщение / симптомЧто проверить
git: command not foundУстановите Git командой sudo apt install git, затем проверьте git --version.
gcc: command not foundУстановлен ли пакет build-essential.
CUnit/Basic.h: No such file or directoryУстановлен ли libcunit1-dev.
cannot find -lcunitПереустановите пакет: sudo apt install --reinstall libcunit1-dev.
Package libcunit1-dev has no installation candidateПроверьте подключённые репозитории вашей версии Linux и обновите список пакетов.

Другие дистрибутивы

Названия пакетов и команды установки могут отличаться в Fedora, Arch Linux и других системах. Используйте менеджер пакетов своего дистрибутива, чтобы установить CUnit и инструменты сборки. После установки команды в примере остаются такими же, если доступны GCC и Make.
