Урок #2: Условный оператор

В этом уроке вы научитесь управлять поведением программы с помощью условий: if, elif и else.

📚 Условный оператор

Условный оператор позволяет программе принимать решения. В Python он записывается с помощью ключевых слов if, elif (else if) и else.

Пример:
if x > 0:
    print("Положительное")
elif x == 0:
    print("Ноль")
else:
    print("Отрицательное")

Логические операторы позволяют комбинировать условия:

  • and — оба условия истинны
  • or — хотя бы одно условие истинно
  • not — отрицание условия

Пример: if age >= 18 and has_passport:

Важно! После if, elif и else обязательно ставится двоеточие :, а тело условия записывается с отступом (обычно 4 пробела).

Python не использует фигурные скобки — отступы определяют структуру кода!

🐍 Интересный факт

Условный оператор существует почти во всех языках программирования, но в Python его синтаксис считается одним из самых читаемых и элегантных. Это делает код похожим на обычный английский текст!

💡 Советы по решению задач

  • Всегда проверяйте граничные значения (например, 0, отрицательные числа).
  • Используйте elif, а не вложенные if, если условия взаимоисключающие.
  • Для сравнения строк учитывайте регистр: "Ананас" != "ананас".

Пример: Проверка возраста

age = int(input("Сколько вам лет? "))
if age < 12:
    print("Вам нельзя на этот фильм!")
else:
    print("Добро пожаловать!")

Входные данные: duration (int) — минут на парковке, hour (int) — час въезда (0–23).

Выходные данные: стоимость (int, ₽).

Примеры:

90 мин, 14:00 → 100 ₽
180 мин, 14:00 → 250 ₽

Задача 8: Ладья 🏰

Ладья ходит по прямой: либо по горизонтали, либо по вертикали, на любое число клеток. Напиши программу, которая по координатам двух клеток определяет, может ли ладья за один ход попасть с первой на вторую.

Входные данные: четыре числа x1, y1, x2, y2 — где стоит ладья и куда хочет пойти. Все от 1 до 8.

Выходные данные: "Да" или "Нет".

Примеры:

3 5 → 3 8   → Да (одна вертикаль)
3 5 → 7 5   → Да (одна горизонталь)
3 5 → 4 6   → Нет (диагональ — не её стиль)
3 5 → 3 5   → Да (никуда не идти тоже можно)

Подсказка: у ладьи либо совпадают x, либо совпадают y. Запиши это через or в одном if.

Усложнение: добавь проверку — если координаты вне диапазона 1–8, выведи "Нет такой клетки".

Задача 9: Слон 🧙

Слон ходит только по диагонали, на любое число клеток. Определи, может ли слон за один ход попасть из первой клетки во вторую.

Входные данные: четыре числа x1, y1, x2, y2 (1–8).

Выходные данные: "Да" или "Нет".

Примеры:

2 2 → 5 5   → Да (по главной диагонали)
2 2 → 5 6   → Нет
4 7 → 1 4   → Да (разница 3 и 3)
3 3 → 3 4   → Нет (слон так не умеет)

Задача 10: Ферзь 👑

Ферзь — самая сильная фигура: он ходит и как ладья (по прямой), и как слон (по диагонали). Определи, может ли ферзь за один ход попасть из первой клетки во вторую.

Входные данные: x1, y1, x2, y2 (1–8).

Выходные данные: "Да" или "Нет".

Примеры:

3 3 → 3 7   → Да (по вертикали)
3 3 → 8 3   → Да (по горизонтали)
3 3 → 6 6   → Да (по диагонали)
3 3 → 4 6   → Нет
