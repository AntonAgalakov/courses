Раздел 01

Теоретический материал

Вложенные списки и работа с ними

1.1. Что такое вложенный список

Вложенный список — это список, элементами которого являются другие списки. В Python такие структуры используются для представления прямоугольных таблиц (матриц).

A = [[1, 2, 3], [4, 5, 6]]

Здесь A[0] — первая строка [1, 2, 3], а A[1] — вторая [4, 5, 6]. Доступ к отдельному элементу — по двум индексам:

print(A[0][0])  # 1
print(A[1][2])  # 6

1.2. Создание вложенных списков

Пусть даны n — количество строк, m — количество столбцов. Создадим список n×m, заполненный нулями.

Способ 1. Создать список из n элементов и заменить каждый на новый список из m нулей.

A = [0] * n
for i in range(n):
    A[i] = [0] * m

Способ 2. Создать пустой список и добавлять строки по одной.

A = []
for i in range(n):
    A.append([0] * m)
⚠️
Осторожно: A = [[0] * m] * n создаёт n ссылок на один и тот же список. Изменение одной строки изменит все.

1.3. Обход и вывод

Для обхода матрицы используется два вложенных цикла: внешний — по строкам, внутренний — по элементам строки.

for i in range(len(A)):
    for j in range(len(A[i])):
        print(A[i][j], end=' ')
    print()

Длина каждой строки может быть разной, но для прямоугольных таблиц она одинакова: len(A[i]) == m для всех i.

2.4. lambda, filter и sorted

lambda — анонимная функция из одного выражения. Удобна, когда функция нужна один раз:

double = lambda x: x * 2
print(double(5))  # 10

filter(f, lst) — оставляет только те элементы, для которых f(x) истинно. Возвращает итератор, поэтому результат обычно оборачивают в list():

nums = [1, 2, 3, 4, 5, 6]
evens = list(filter(lambda x: x % 2 == 0, nums))
print(evens)  # [2, 4, 6]

sorted(lst, key=...) — возвращает новый отсортированный список. Параметр key принимает функцию, по которой сравниваются элементы:

words = ["кот", "слон", "я"]
print(sorted(words, key=lambda w: len(w)))  # ['я', 'кот', 'слон']

Комбинация filter + sorted позволяет и отобрать нужные элементы, и упорядочить их:

nums = [5, 3, 8, 1, 9, 2]
result = sorted(filter(lambda x: x > 3, nums), reverse=True)
print(result)  # [9, 8, 5]

Разбор A5

Численное интегрирование: метод прямоугольников

Определённый интеграл функции f(x) от a до b — это число, равное площади криволинейной трапеции: фигуры, ограниченной прямыми x = a, x = b, y = 0 и кривой y = f(x).

В этой работе функция подобрана так, что на всём отрезке [−2; 5] она не касается оси x — график всюду выше неё, поэтому площадь фигуры положительна и хорошо видна на схеме.

Точное значение — это предел суммы:

∫ab f(x) dx = limΔx→0 Σ f(xi) · Δxi

На практике предел не вычисляют — считают приближённо, разбивая отрезок на N частей. Чем больше N, тем точнее результат.

Равномерная сетка

Отрезок [a; b] разбивается на N равных частей с шагом h. Точки разбиения:

h = (b − a) / N,    xi = a + i · h,    i = 0..N−1

Метод прямоугольников

Криволинейная трапеция заменяется множеством прямоугольников шириной h. Высота каждого — значение функции f(x_i) в соответствующей точке.

Метод левых прямоугольников (N = 10)■ Приближённая площадь

Каждый прямоугольник имеет высоту f(xᵢ); площадь суммируется как f(xᵢ) · h.

Схема для понимания метода: увеличивайте N в программе, чтобы уменьшать ширину h и уточнять сумму.

S ≈ Σi=0..N−1 f(xi) · h
ℹ️
Метод приближённый: чем больше N, тем точнее результат и ближе к настоящему значению интеграла.

Метод трапеций (для сравнения)

Фигура под графиком заменяется суммой обычных трапеций. Крайние точки берутся с половинным весом:

Метод трапеций (N = 10)■ Приближённая площадь

На каждом участке кривая заменяется отрезком; площадь — сумма трапеций.

Схема для понимания метода: увеличивайте N в программе, чтобы уменьшать ширину h и уточнять сумму.

S ≈ (h/2)·(f0 + fN−1) + Σi=1..N−2 fi · h

Этот метод используется в задании 2 — там нужно будет реализовать его самостоятельно.

Решение · метод прямоугольников
def func(x):
    return x ** 2 / 10 + 1

# Отрезок и число разбиений
a, b = -2, 5
N = 1000

# Шаг сетки
h = (b - a) / N

# Вычисляем значения функции в точках сетки
values = []
for i in range(N):
    x_i = a + i * h
    values.append(func(x_i))

# Суммируем площади прямоугольников
S = 0
for v in values:
    S += v * h

print(f"S = {S:.2f}")
Вывод для разных N
N = 10:    S ≈ 10.76    (грубо)
N = 100:   S ≈ 11.36    (точнее)
N = 1000:  S ≈ 11.43    (ещё точнее)
N = 10000: S ≈ 11.43    (почти сошлось)
💡
Что нужно сделать в задании 1. Реализовать тот же алгоритм и вывести значения интеграла для N = 10, 100, 1000, 10000.
⚠️
Проверка сходимости. Значения для разных N должны быть близки друг к другу и постепенно сходиться к настоящему значению интеграла (≈ 11.43). Если они «скачут» — проверьте формулу и границы цикла.

Магический квадрат

Магический квадрат — это квадратная таблица n×n, заполненная числами от 1 до n² так, что суммы чисел по всем строкам, всем столбцам и обеим главным диагоналям одинаковы.

Эта общая сумма называется «магической константой» и равна n·(n² + 1) / 2.

◆ Условие

Напишите программу, которая генерирует случайный магический квадрат нечётного порядка n (n вводится с клавиатуры, например 3 или 5).

Шаги:

  1. Постройте магический квадрат для нечётного n по правилу «сиамского метода»: начинаем с 1 в центральной ячейке верхней строки, далее двигаемся вверх-вправо, а при выходе за границы «оборачиваемся».
  2. Случайным образом перемешайте строки, столбцы и значения (сохраняя магическое свойство).
  3. Выведите квадрат на экран.
  4. Проверьте и выведите магическую константу и убедитесь, что суммы совпадают.

Пример

2 7 6
9 5 1
4 3 8

Сумма по каждой строке/столбцу/диагонали = 15.

💡
Для перемешивания используйте random.shuffle. Нечётный порядок — обязательное условие сиамского метода.

Задание 10

Токинезатор

◆ Условие

Напишите функцию tokenize(text) -> list[str], которая разбивает строку на слова (токены) по следующим правилам:

  • Разделители: пробелы, табы, \n, знаки .,;:!?()[]{}"«»…—–.
  • Дефис и апостроф внутри слова — часть слова: "кто-то", "don't".
  • Числа, включая десятичные — отдельные токены: "3.14" → ["3.14"]. Точка внутри числа — не разделитель.
  • Пустые токены не появляются.

Ограничение: нельзя использовать re и str.split(). Только цикл по символам.

Примеры работы
tokenize("Привет, мир! Как дела?")     # ["Привет", "мир", "Как", "дела"]
tokenize("Жили-были 3.14 раза")        # ["Жили-были", "3.14", "раза"]
tokenize("s = \"don't\"")              # ["s", "don't"]
tokenize("A...B")                      # ["A", "B"]
tokenize("")                           # []
💡
Заведите буфер текущего слова. Идите по символам: если символ — разделитель, «сбрасывайте» буфер в результат. Особый случай — точка: она разделитель, кроме случая, когда между двумя цифрами.

Задание 12

Конвертор

◆ Условие

Напишите функцию markdown_to_html(md) -> str, которая превращает простой Markdown в HTML.

Вход: строка, в которой строки разделены символом \n.

Выход: строка с HTML-кодом, строки разделены тем же \n.

Правило 1 · Заголовки

Строка начинается с одного–шести символов #, затем идёт пробел. Уровень заголовка равен количеству #. Сами # и пробел после них убираются.

ВходВыход
# Заголовок<h1>Заголовок</h1>
## Подзаголовок<h2>Подзаголовок</h2>
### Тема<h3>Тема</h3>
###### Мелкий<h6>Мелкий</h6>

Правило 2 · Жирный текст

Внутри строки **слово** заменяется на <b>слово</b>.

ВходВыход
Это **важно**<p>Это <b>важно</b></p>

Правило 3 · Код

Внутри строки `x` заменяется на <code>x</code>.

ВходВыход
Команда `print()`<p>Команда <code>print()</code></p>

Правило 4 · Абзац

Если строка не начинается с #, она оборачивается в <p>…</p>.

Пример
ВХОД:
# Заголовок
## Подзаголовок
Это **жирный** текст и `код`.

ВЫХОД:
<h1>Заголовок</h1>
<h2>Подзаголовок</h2>
<p>Это <b>жирный</b> текст и <code>код</code>.</p>
Тесты для самопроверки
assert markdown_to_html("# Привет") == "<h1>Привет</h1>"
assert markdown_to_html("### Тема") == "<h3>Тема</h3>"
assert markdown_to_html("###### Мелкий") == "<h6>Мелкий</h6>"
assert markdown_to_html("Это **важно**") == "<p>Это <b>важно</b></p>"
assert markdown_to_html("Код `x`") == "<p>Код <code>x</code></p>"
assert markdown_to_html("") == ""
