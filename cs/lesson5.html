Циклы и строки в Python
на практике

Учимся повторять действия и обрабатывать текст: перебор символов, счётчики, накопление результата, поиск в строках — с примерами для тех, кто раньше не программировал.

Раздел 01

Теоретические сведения

Зачем нужны циклы, как устроены for и while, и какие инструменты помогают ими управлять

1.1. Что такое цикл и зачем он нужен

Цикл — это конструкция, которая позволяет программе выполнить один и тот же блок команд несколько раз. Если нужно вывести числа от 1 до 100, писать сто строк print(...) неудобно. Цикл записывает это коротко и понятно.

В Python есть два основных вида циклов:

  • for — перебирает элементы последовательности: числа, строки, списки, словари.
  • while — выполняется до тех пор, пока условие истинно.
ℹ️
Важно. В Python тело цикла выделяется отступами (обычно 4 пробела). Это часть синтаксиса, а не украшение. Забыли отступ — программа не запустится.

1.2. Цикл for

Используется, когда мы перебираем элементы последовательности. Читается так: «для каждого элемента из последовательности выполнить тело цикла».

for переменная in последовательность:
    тело_цикла

Пример — вывести числа от 0 до 4:

for i in range(5):
    print(i)

Что происходит:

  • range(5) создаёт последовательность 0, 1, 2, 3, 4.
  • Переменная i по очереди принимает каждое значение.
  • Для каждого значения выполняется print(i).

Результат:

0
1
2
3
4

1.3. Функция range()

range() помогает создать последовательность чисел. У неё может быть один, два или три аргумента.

ЗаписьЧто даёт
range(5)0, 1, 2, 3, 4
range(2, 6)2, 3, 4, 5
range(1, 10, 2)1, 3, 5, 7, 9
range(5, 0, -1)5, 4, 3, 2, 1
⚠️
Верхняя граница не включается. range(5) даёт числа от 0 до 4, но не 5. Это одна из самых частых ошибок новичков.

1.4. Перебор строки

Строка — цикл перебирает отдельные символы:

word = "Python"

for letter in word:
    print(letter)

1.5. Цикл while

Выполняется, пока условие истинно. Используется, когда количество повторений заранее неизвестно.

while условие:
    тело_цикла

Пример — обратный отсчёт от 5 до 1:

n = 5

while n > 0:
    print(n)
    n -= 1

Что происходит:

  • Пока n > 0, тело цикла выполняется.
  • n -= 1 уменьшает n на 1.
  • Когда n становится равно 0, условие перестаёт быть истинным — цикл завершается.
⚠️
Бесконечный цикл. Если условие никогда не станет ложным, программа зависнет. Например, while True: print("∞") без break будет работать вечно.

break — досрочно выйти из цикла:

1.7. Вложенные циклы

Один цикл может находиться внутри другого. Внешний делает один «шаг», внутренний полностью проходит все свои значения.

for i in range(1, 4):
    for j in range(1, 4):
        print(f"{i} * {j} = {i * j}")
    print()
1 * 1 = 1
1 * 2 = 2
1 * 3 = 3

2 * 1 = 2
2 * 2 = 4
2 * 3 = 6

3 * 1 = 3
3 * 2 = 6
3 * 3 = 9

Типичное применение — таблицы умножения, матрицы, всевозможные комбинации.

1.8. Типичные ошибки

1. Забыли двоеточие

for i in range(5)   # ошибка
    print(i)

2. Неправильные отступы

for i in range(5):
print(i)            # ошибка: нет отступа

3. Бесконечный while

i = 0
while i < 5:
    print(i)        # i не изменяется — цикл вечный

4. Путаница с границами range()

for i in range(1, 5):
    print(i)
# выведет 1, 2, 3, 4 — но не 5

Раздел 03

Строки в Python

Что такое строка, как получить отдельный символ или его часть, и как циклы помогают обрабатывать текст

3.1. Что такое строка

Строка (string) — это последовательность символов, заключённая в кавычки. В Python можно использовать одинарные, двойные или тройные кавычки — результат один и тот же.

a = "Привет"
b = 'Мир'
c = "Python — это язык программирования"
d = """Многострочная
строка"""

Строка — это последовательность. Это значит, что её можно перебирать в цикле for точно так же, как список: цикл по очереди выдаёт символы.

for ch in "abc":
    print(ch)
a
b
c
ℹ️
Строки неизменяемы (immutable). После создания строки её нельзя изменить «на месте»: s[0] = "X" вызовет ошибку. Вместо этого создают новую строку — например, через срезы и склейку.

3.2. Индексы и срезы

Каждый символ строки имеет свой номер (индекс). Нумерация начинается с нуля.

s = "Python"
#    P  y  t  h  o  n
#    0  1  2  3  4  5
0P-6
1y-5
2t-4
3h-3
4o-2
5n-1

Обращаться к символу можно по индексу:

s = "Python"
print(s[0])     # P
print(s[1])     # y
print(s[-1])    # n — последний символ
print(s[-2])    # o — предпоследний

Срез — «кусок» строки, заданный двумя индексами: s[start:stop]. Символ с индексом start включается, а с индексом stop — нет.

s = "Python"

print(s[0:3])    # Pyt
print(s[2:5])    # tho
print(s[:3])     # Pyt  — с начала
print(s[3:])     # hon  — до конца
print(s[:])      # Python — вся строка
print(s[::2])    # Pto  — каждый второй символ
print(s[::-1])   # nohtyP — перевёрнутая строка
💡
Запомните. В срезе правая граница не включается — так же, как в range(). Это удобно, потому что длина среза s[a:b] всегда равна b - a.

3.3. Длина строки — len()

Функция len() возвращает количество символов в строке:

s = "Python"
print(len(s))     # 6

word = "Привет, мир!"
print(len(word))  # 13

Пробелы и знаки препинания тоже считаются символами.

3.4. Перебор строки в цикле

Самый частый способ обработки текста — пройтись по каждому символу через цикл for.

По символам:

word = "hello"
count = 0

for ch in word:
    if ch == "l":
        count += 1

print(count)      # 2

По индексам — когда нужен номер символа или доступ к соседним:

word = "hello"

for i in range(len(word)):
    print(i, word[i])
0 h
1 e
2 l
3 l
4 o

Или через enumerate() — короче и понятнее:

for i, ch in enumerate("hello"):
    print(i, ch)
ℹ️
Когда что использовать. Если нужен только символ — for ch in word. Если нужен ещё и индекс — enumerate(). Классический for i in range(len(word)) нужен, только когда вы обращаетесь к word[i] и word[i+1] одновременно.

3.5. Основные методы строк

У строки есть «встроенные команды» — методы. Вызываются через точку: s.upper().

МетодЧто делаетПример → результат
s.upper()все буквы заглавные"abc".upper() → "ABC"
s.lower()все буквы строчные"AbC".lower() → "abc"
s.strip()убрать пробелы по краям" hi ".strip() → "hi"
s.split()разбить по пробелам"a b".split() → ["a","b"]
s.replace(a, b)заменить все вхождения"aaa".replace("a","b") → "bbb"
s.count(x)сколько раз встречается"banana".count("a") → 3
s.find(x)индекс первого вхождения"hello".find("l") → 2
x in sесть ли подстрока"ell" in "hello" → True
 
text = "  Hello, World!  "
print(text.strip())          # "Hello, World!"
print(text.strip().upper())  # "HELLO, WORLD!"
print("a,b,c".split(","))    # ["a", "b", "c"]
print("hello".count("l"))    # 2
print("hello".find("lo"))    # 3

3.6. Склейка, повторение и f-строки

Склейка (конкатенация) — оператор +:

greeting = "Привет, " + "мир!"
print(greeting)          # Привет, мир!

Повторение — оператор *:

print("ab" * 3)          # ababab
print("-" * 20)          # --------------------

f-строки — самый удобный способ вставить значение переменной внутрь текста. Перед кавычками ставится f, а в фигурных скобках — имя переменной:

name = "Анна"
age = 20
print(f"Меня зовут {name}, мне {age} лет")
# Меня зовут Анна, мне 20 лет

# Можно даже выражения внутри скобок
print(f"2 + 3 = {2 + 3}")   # 2 + 3 = 5
print(f"Длина: {len(name)}")  # Длина: 4
⚠️
Ошибка. Нельзя складывать строку и число: "x = " + 5 вызовет TypeError. Нужно либо "x = " + str(5), либо (лучше) f-строка: f"x = {5}".

3.7. Как циклы работают со строками

Три классических шаблона, которые пригодятся почти в каждой задаче.

Шаблон 1. Счётчик. Перебираем строку и считаем, сколько раз что-то встретилось.

text = "Programming"
count = 0

for ch in text.lower():
    if ch == "g":
        count += 1

print(count)      # 2

Шаблон 2. Накопление новой строки. Собираем результат по символам.

word = "abc"
result = ""

for ch in word:
    result = ch + result     # добавляем новый символ в начало

print(result)      # cba

Шаблон 3. Фильтрация. Оставляем только нужные символы.

s = "a1b2c3d4"
letters = ""

for ch in s:
    if ch.isalpha():         # если буква
        letters += ch

print(letters)     # abcd
💡
Полезные проверки символа: ch.isalpha() — буква, ch.isdigit() — цифра, ch.isspace() — пробел/перевод строки, ch.isupper() — заглавная буква, ch.islower() — строчная.

3.8. Что важно помнить

  • Строка неизменяема. Нельзя s[0] = "X" — придётся строить новую строку.
  • Сравнение — не присваивание. == сравнивает, = присваивает. Внутри if — всегда двойное равно.
  • Индексы от 0 до len(s) - 1. Выход за границы — ошибка IndexError.
  • Регистр имеет значение. "Python" и "python" — разные строки. Для сравнения без учёта регистра используйте .lower() с обеих сторон.
  • Срез не портит оригинал. s[1:3] возвращает новую строку, исходная s не меняется.

Хайку — жанр традиционной японской лирики. Оригинальное хайку состоит из 17 слогов: 5 + 7 + 5. При переводе на западные языки хайку записывается как трёхстишие. Будем считать, что слогов ровно столько же, сколько гласных.

◆ Задание
Реализуйте программу, которая считывает три строки и проверяет: 5 / 7 / 5 слогов соответственно. Если схема слогов не 5/7/5 — Не хайку. Иначе — Хайку!

Задание 16

Метод бутерброда

Секретное агентство «Super-Secret-no» решило для шифрования переписки своих сотрудников использовать «метод бутерброда». Сначала буквы слова нумеруются: первая буква получает номер 1, последняя буква — номер 2, вторая — номер 3, предпоследняя — номер 4, потом третья… и так для всех букв. Затем все буквы записываются в шифр в порядке своих номеров, и в конец зашифрованного слова добавляется #, который нельзя использовать в сообщениях.

К сожалению, программист «Super-Secret-no» написал только программу шифрования и уволился. И теперь агенты не могут понять, что же они написали друг другу. Помогите им.

◆ Задание
Реализуйте программу, которая считывает зашифрованное слово (с символом # в конце) и восстанавливает исходное. Если символа # в конце нет — вывести Ошибка! Отсутствует символ #.

camelCase → snake_case
