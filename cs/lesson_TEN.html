2.1. Работа с текстовыми файлами (.txt)

В Python для открытия файлов используется функция open(). Однако лучшей практикой считается использование конструкции with open(...). Она автоматически закрывает файл после завершения блока кода, даже если внутри произошла ошибка.

# Открытие файла для чтения ('r' - read)
with open("file.txt", "r", encoding="utf-8") as f:
    content = f.read() # Читает весь файл в одну строку

# Открытие файла для записи ('w' - write). ВНИМАНИЕ: старые данные стираются!
with open("new_file.txt", "w", encoding="utf-8") as f:
    f.write("Текст для записи\n")

# Открытие для добавления ('a' - append). Данные допишутся в конец.
with open("file.txt", "a", encoding="utf-8") as f:
    f.write("Новая строка\n")
⚠️
Кодировка: Всегда указывайте encoding="utf-8", иначе русские буквы могут превратиться в «кракозябры».

Читать файл можно построчно (это экономит память при работе с большими файлами):

with open("file.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip()) # strip() убирает невидимый символ переноса строки (\n)

2.2. Парсинг строк: split() и rsplit()

Данные в файлах часто хранятся в виде строк, разделенных пробелами или запятыми. Чтобы извлечь из них информацию, строку нужно «разрезать».

  • split() — делит строку по пробелам (или другому символу) слева направо.
  • rsplit() — делит строку справа налево. Это критически важно, если начало строки содержит пробелы, а конец — строго одно значение (например, число).
line = "Иванов Иван 85"
# Обычный split разделит на 3 части
print(line.split()) # ['Иванов', 'Иван', '85']

# rsplit(maxsplit=1) сделает только 1 разрез справа
print(line.rsplit(maxsplit=1)) # ['Иванов Иван', '85']

2.3. Словари (dict): основа JSON

Словарь в Python — это структура данных, хранящая пары «ключ-значение». JSON при чтении в Python превращается именно в словари (и списки).

data = {"name": "Иван", "age": 25}

# Доступ по ключу
print(data["name"]) # Иван

# Безопасный доступ (если ключа нет, вернет 0 вместо ошибки)
print(data.get("salary", 0)) # 0

# Добавление или изменение
data["age"] = 26
data["city"] = "Москва"

# Перебор всех ключей и значений
for key, value in data.items():
    print(key, value)

2.4. Модуль JSON

Модуль json позволяет сохранять словари на диск и загружать их обратно. Это стандартный формат обмена данными в современном программировании.

import json

# Запись словаря в файл
my_dict = {"a": 1, "b": 2}
with open("data.json", "w", encoding="utf-8") as f:
    json.dump(my_dict, f, ensure_ascii=False, indent=4)
    # ensure_ascii=False — сохраняет кириллицу читаемой
    # indent=4 — делает файл красивым (с отступами)

# Чтение JSON из файла
with open("data.json", "r", encoding="utf-8") as f:
    loaded_data = json.load(f)
print(loaded_data["a"]) # 1

2.5. Сложные структуры: списки внутри словарей

В реальных JSON-файлах данные часто вложены друг в друга. Например, словарь содержит список, внутри которого лежат другие словари.

{
    "category": "Fruits",
    "items": [
        {"name": "Apple", "price": 10},
        {"name": "Banana", "price": 5}
    ]
}

Чтобы добраться до цены банана, нужно сначала обратиться к ключу словаря, затем к индексу списка, и затем к ключу вложенного словаря:

print(data["items"][1]["price"]) # 5

Если нужно перебрать все элементы списка, используется обычный цикл for:

for item in data["items"]:
    print(item["name"])

Задание 5

SEO Анализ текста

◆ Условие

Вам нужно проанализировать текст статьи и понять, какие слова автор использует чаще всего (чтобы потом на них сделать упор в рекламе).

Напишите программу, которая читает файл article.txt, очищает текст от знаков препинания (точек, запятых, восклицательных знаков). Разбейте текст на отдельные слова. Посчитайте, сколько раз встречается каждое слово (регистр не важен). Выведите на экран ТОП-5 самых частых слов и количество их повторений.

Подсказки

  • Приведите весь текст к нижнему регистру через .lower().
  • Используйте модуль string.punctuation или цикл для удаления знаков.
  • Словарь (dict) отлично подходит для подсчета: ключ — слово, значение — счетчик.
  • Для сортировки словаря по значениям используйте sorted(d.items(), key=lambda x: x[1], reverse=True).
