Теоретические сведения

Условные конструкции, логические операторы, приоритеты и типичные ошибки

1.1. Основная конструкция if

Условная конструкция позволяет выполнять разные блоки кода в зависимости от того, истинно ли некоторое выражение. В Python блоки выделяются отступами — обычно 4 пробела. Отступы обязательны, это часть синтаксиса.

if условие:
    # выполняется, если условие истинно
    действие_1
elif другое_условие:
    # выполняется, если первое ложно, а второе истинно
    действие_2
else:
    # выполняется, если все предыдущие условия ложны
    действие_3

Как это читается. Python проверяет условия сверху вниз. Как только находит первое истинное — выполняет соответствующий блок и пропускает все остальные ветви (даже если они тоже истинны). Если ни одно условие не сработало — выполняется блок else, если он есть.

ℹ️
Важно. elif — это сокращение от «else if». Их может быть сколько угодно. else — максимум один, и он всегда идёт последним.

1.4. Приоритет операторов и скобки

При вычислении составных условий Python действует по правилам, похожим на арифметику: сначала not, потом and, только потом or. Скобки меняют порядок — как в математике.

# Без скобок: not → and → or
A or B and C       # читается как   A or (B and C)

# Со скобками — как удобно вам
(A or B) and C     # совсем другое условие!
💡
Совет. Даже если помните приоритеты — ставьте скобки. Это делает условие понятнее и защищает от ошибок. Особенно там, где смешиваются and и or.

1.5. Проверка принадлежности диапазону

«Внутри диапазона» — это два условия, соединённых через and. В Python можно записать короче, как в математике:

# Полная форма
if x >= 10 and x <= 20:
    print("в диапазоне")

# Сокращённая форма (работает так же)
if 10 <= x <= 20:
    print("в диапазоне")

Границы включительно или нет. Запись [a, b] означает включая оба конца, запись (a, b) — не включая. Это важно для задач про интервалы и тарифы: например, «до 30 минут» — это < 30, а «от 30 до 120» — >= 30 and <= 120.

1.6. Конструкция match / case

Появилась в Python 3.10. Удобна, когда одна переменная сравнивается с целым набором конкретных значений — например, коды ошибок, статусы, дни недели.

match code:
    case 100:
        print("Ошибка конфигурации")
    case 101:
        print("Неизвестный параметр")
    case 200 | 201:                       # можно объединять варианты
        print("Соединение")
    case _:                               # по умолчанию, «во всех остальных случаях»
        print("Unknown error")
ℹ️
Важно. case _: — это аналог else. Он должен идти последним. Без него при неизвестном значении ничего не выполнится.

1.7. Чтение данных с клавиатуры

Функция input() всегда возвращает строку. Чтобы получить число, результат нужно преобразовать через int() или float().

age = int(input())            # целое число
price = float(input())        # вещественное число
name = input()                # строка — оставляем как есть
letter = input().strip()      # строка без лишних пробелов по краям
⚠️
Частая ошибка: сравнить input() с числом напрямую — например, if input() == 5. Строка никогда не равна числу, условие всегда ложно. Сначала int(), потом сравнение.

1.8. Граничные случаи

Это значения, стоящие ровно на границе между разными ветвями алгоритма. Их обязательно проверять тестами: именно там прячутся самые коварные баги.

Пример. В задаче про тариф: «до 30 минут — 0 ₽, от 30 до 120 — 100 ₽». Граничное значение — 30. Куда оно попадает? Если условие написано как duration < 30 — в первую ветвь. Если как duration <= 30 — тоже в первую. Ошибка появляется, когда граница «проваливается» сразу в две ветви или не попадает ни в одну.

💡
Правило хорошего тона. Для каждой задачи с диапазонами прогоните программу на трёх числах: левая граница, правая граница, значение вне диапазона. Именно так построены примеры в заданиях ниже.

1.9. Типичный каркас программы-решения

Почти любое задание этой лабораторной укладывается в один и тот же шаблон:

# 1. Считать входные данные
a = int(input())
b = int(input())

# 2. Проверить условия (при необходимости — с приоритетами)
if первое_условие:
    результат = "вариант 1"
elif второе_условие:
    результат = "вариант 2"
else:
    результат = "по умолчанию"

# 3. Вывести результат
print(результат)

Держите этот каркас в голове — и любая задача из восьми ниже сведётся к аккуратной расстановке условий и их приоритетов.

Задание 7

Логический замок

Гоша — начинающий «безопасник». Ему в руки попал старенький сейф с четырьмя тумблерами на дверце, подписанными A, B, C, D. Прежний владелец оставил записку с правилом срабатывания, но проверять его вручную — сущее мучение: тумблеров четыре, комбинаций шестнадцать, и легко запутаться. Гоша хочет написать маленького бота-взломщика: вводишь четыре нуля и единицы — и сразу видно, щёлкнул бы замок или остался закрытым.

◆ Задание
Реализуйте программу, которая считывает четыре значения — состояния переключателей A, B, C, D (каждое — 0 или 1, по одному в строке) — и выводит OPEN, если замок открывается, или CLOSED — если нет.

Правило срабатывания замка

  1. Блокировка. Если A = 1 и D = 1 одновременно — замок заблокирован, независимо от остальных переключателей. Результат: CLOSED.
  2. Иначе замок открывается, если выполнено хотя бы одно из условий:
    • включён A и выключен B;
    • включены одновременно C и D.
  3. Во всех остальных случаях — CLOSED.
