Раздел 01

Теория: как устроен графический интерфейс

Разберём Tkinter на небольших независимых примерах и схемах. Они знакомят с инструментами библиотеки, но не повторяют практические задания.

1.1. Tkinter — конструктор окон

Tkinter — стандартная библиотека Python для создания графических интерфейсов (GUI — Graphical User Interface). С её помощью программа может показывать окна, текст, поля, кнопки и другие элементы, с которыми взаимодействует пользователь.

🧩
Представьте конструктор: окно — это основа, виджеты — детали, менеджер геометрии — способ расположить детали, а обработчики событий — правила поведения интерфейса.

import tkinter as tk

1.2. Из чего состоит окно

Главное окно создаётся вызовом tk.Tk(). После создания ему можно задать заголовок, размеры и другие свойства.

import tkinter as tk

root = tk.Tk()
root.title("Информационная панель")
root.geometry("460x300")
root.configure(bg="#f1f5f9")

root.mainloop()

1.3. Виджеты: детали интерфейса

Виджет — отдельный элемент графического интерфейса. У каждого виджета есть назначение и набор параметров.

LABEL
Заголовок

Показывает текст или изображение.

BUTTON
Открыть

Запускает действие при нажатии.

ENTRY
Введите имя

Принимает однострочный текст.

FRAME
Группа элементов

Объединяет виджеты в области.

label = tk.Label(root, text="Добро пожаловать")
button = tk.Button(root, text="Открыть")
entry = tk.Entry(root)
panel = tk.Frame(root)

Первый аргумент обычно указывает родительский контейнер — окно или рамку, внутри которой будет находиться элемент.

1.4. Как расположить элементы: pack(), grid() и place()

Создать виджет недостаточно: его нужно разместить в окне. В Tkinter для этого есть три менеджера геометрии. В пределах одного контейнера обычно выбирают один способ размещения и придерживаются его.

pack()

Располагает элементы последовательно.

Блок 1
Блок 2
grid()

Строит сетку из строк и столбцов.

1
2
3
4
place()

Задаёт точные координаты.

x, y
label.pack(pady=10)             # последовательное размещение
# Для сетки указывают номер строки и столбца:
label.grid(row=0, column=0)
# Для точной позиции задают координаты:
label.place(x=30, y=50)
МетодКогда удобен
pack()Когда элементы идут один за другим.
grid()Когда интерфейс похож на таблицу или форму.
place()Когда нужна фиксированная позиция элемента.

1.5. Внешний вид: цвет, шрифт и отступы

Интерфейс должен быть не только функциональным, но и понятным. Большинство стандартных виджетов поддерживает параметры оформления.

label = tk.Label(
    root,
    text="Новости дня",
    bg="#e0f2fe",
    fg="#0f172a",
    font=("Arial", 16, "bold"),
    padx=16,
    pady=10
)
ПараметрЧто задаёт
bgЦвет фона.
fgЦвет текста.
fontШрифт, размер и начертание.
width / heightРазмер виджета (единицы зависят от типа элемента).
padx / padyВнутренние или внешние отступы — в зависимости от места применения.
🎨
Цвет можно записать названием, например "navy", или шестнадцатеричным кодом, например "#2563eb". Для читаемости выбирайте контрастные цвета и не перегружайте окно декоративными элементами.

1.6. События и обработчики

Графическая программа большую часть времени ждёт действий пользователя. Нажатие кнопки, ввод текста или закрытие окна — это события. Функция, которую Tkinter вызывает в ответ на событие, называется обработчиком.

Например, обработчик может показать справочную информацию в отдельном диалоговом окне:

import tkinter as tk
from tkinter import messagebox

def show_info():
    messagebox.showinfo("Справка", "Это демонстрационное окно.")

root = tk.Tk()
root.title("Справочный центр")
root.geometry("300x160")

button = tk.Button(root, text="О программе", command=show_info)
button.pack(pady=35)

root.mainloop()
⚠️
Важно: в параметр command передают имя функции без круглых скобок: command=show_info. Так функция будет вызвана при событии, а не сразу при создании кнопки.

1.7. Получение текста из Entry

Entry — однострочное поле для ввода. Введённые данные можно получить, предварительно вставить или удалить.

entry = tk.Entry(root)

value = entry.get()          # прочитать содержимое
entry.insert(0, "Пример")    # вставить текст с позиции 0
entry.delete(0, tk.END)      # удалить всё содержимое

Значение entry.get() всегда возвращает строку. Если программе нужно работать с числом, строку преобразуют в нужный тип:

age_text = entry.get()
age = int(age_text)       # целое число
price = float("12.50")    # число с дробной частью
💡
Преобразование может завершиться ошибкой, если строка не содержит число. В реальных приложениях проверяйте пользовательский ввод с помощью try / except и сообщайте человеку, что нужно исправить.

1.8. Цикл событий и запуск приложения

Последняя важная команда — mainloop(). Она запускает цикл событий: Tkinter следит за действиями пользователя, обновляет окно и вызывает нужные обработчики.

Создание окна и виджетов
↓
Настройка и размещение элементов
↓
mainloop()
↓
Ожидание событий и обновление интерфейса
Цикл продолжается, пока окно не будет закрыто.

Обычно mainloop() вызывают один раз в конце программы. Если забыть эту команду, приложение не перейдёт в обычный режим ожидания действий пользователя.

Задание 1 · Лёгкое

Случайное предсказание

◆ Условие

Создайте интерфейс, который выдаёт случайное сообщение при нажатии на кнопку.

  • Окно с одной кнопкой: «Скажи мне что-нибудь».
  • При каждом нажатии текст метки меняется на одно из трёх случайных сообщений:
    • «Ты сегодня сделаешь что-то крутое!»
    • «Сегодня — хороший день для чая.»
    • «Твоя следующая оценка — 5!»

Подсказка

  • Используйте random.choice() для выбора сообщения из списка.
  • Не забудьте import random в начале программы.
  • Текст метки меняется через label.config(text=...).
Задание 2 · Лёгкое

Светофор

◆ Условие

Управляйте цветом фона окна через кнопки.

  • Создайте три кнопки: «Красный», «Жёлтый», «Зелёный».
  • При нажатии на любую — фон окна меняется на соответствующий цвет.

Подсказка

  • Фон окна меняется через root.configure(bg="red").
  • Каждой кнопке нужна своя функция-обработчик (или одна функция с параметром через lambda).
💡
Продвинутый вариант: сделайте одну функцию set_color(color) и привяжите её кнопки так: command=lambda: set_color("red").
Задание 3 · Среднее

Угадай число

◆ Условие

Создайте мини-игру с обратной связью на ввод пользователя.

  • Программа случайно загадывает число от 1 до 100 при запуске.
  • Пользователь вводит число в текстовое поле и нажимает кнопку «Угадать».
  • Метка выводит:
    • «Ты угадал!» — если совпало;
    • «Больше!» — если введённое число меньше загаданного;
    • «Меньше!» — если введённое число больше загаданного.

Особенности

  • Загаданное число: random.randint(1, 100).
  • Нужно преобразовывать строку из поля в число: int(entry.get()).
  • Полезно добавить счётчик попыток.
⚠️
Осторожно: если пользователь введёт буквы вместо числа, int() выбросит ошибку ValueError. Обработайте её через try / except.
Каркас решения
def check_guess():
    try:
        guess = int(entry.get())
    except ValueError:
        label.config(text="Введите число!")
        return

    if guess == secret:
        label.config(text="Ты угадал!")
    elif guess < secret:
        label.config(text="Больше!")
    else:
        label.config(text="Меньше!")
Задание 4 · Среднее

Программа, которая не работает

◆ Условие

Создайте интерфейс, который ничего не делает — пока не будет выполнено условие.

  • Окно с одной кнопкой: «Запустить».
  • При первых 6 нажатиях — ничего не происходит.
  • Только при 7-м нажатии подряд появляется метка: «Ты настойчив! Вот тебе сюрприз: ты победил!»

Особенности

  • Нет визуальных подсказок, цветов и анимаций до 7-го нажатия.
  • Это программа на терпение и ожидание — классическая пасхалка в программе.
  • Никаких других эффектов! Только счётчик.
Каркас решения
clicks = 0

def on_click():
    global clicks
    clicks += 1
    if clicks == 7:
        label.config(text="Ты настойчив! Вот тебе сюрприз: ты победил!")
💡
Метку лучше создать заранее с пустым текстом (text="") и только менять её содержимое на 7-м нажатии.
Задание 5 · Среднее

Секретная кнопка

◆ Условие

Найдите одну «правильную» кнопку среди четырёх — без подсказок.

  • Создайте окно с четырьмя кнопками.
  • Одна из них — секретная (выбирается случайно при запуске).
  • При нажатии:
    • на секретной кнопке — появляется метка: «Поздравляем! Ты нашёл секрет!»;
    • на остальных — «Попробуй ещё!».

Подсказка

  • Секретный номер: secret = random.randint(0, 3).
  • Каждой кнопке нужен свой номер — удобно использовать lambda i=i: check(i).
Задание 6 · Творческое

Конвертер валют

◆ Условие

Создайте приложение, которое конвертирует сумму из рублей в другие валюты: USD, EUR, GBP, JPY.

💱 Представьте, что вы делаете приложение для туриста: ввёл сумму в рублях — сразу увидел, сколько это в долларах, евро, фунтах и йенах. А может, наоборот: выбрал валюту из списка и получил результат.

Обязательные элементы

  1. Использование grid() для размещения элементов (а не pack()).
  2. Творческое оформление: флаги, иконки валют, цвета, шрифты, рамки, градиенты, иконки — всё на ваше усмотрение.
⭐
Критерии оценки: используется grid · есть ввод суммы и выбор валюты · результат выводится корректно · оформление нестандартное (цвета, шрифты, рамки, иконки) · программа не падает при пустом вводе.
