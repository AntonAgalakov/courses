Раздел 01

Теоретический материал

Основы работы с библиотекой Matplotlib

1.1. Что такое Matplotlib

Matplotlib — библиотека Python для создания графиков и диаграмм. Основной модуль для построения — matplotlib.pyplot, который традиционно импортируется под псевдонимом plt.

import matplotlib.pyplot as plt
import numpy as np

График строится на объекте Figure (всё изображение целиком), внутри которого находятся Axes (оси с данными). Самый простой способ создать их — функция plt.subplots():

fig, ax = plt.subplots()

1.2. Линейный график: plot()

Функция plot(x, y) строит зависимость y от x, соединяя точки линией. Можно задавать цвет, толщину, маркеры:

ax.plot(x, y, color='steelblue', linewidth=2, marker='o', label='Данные')

Ключевые параметры стиля:

1.3. Столбчатая диаграмма: bar()

Функция bar(x, height) рисует вертикальные столбики. Высота столбика — значение height, позиция по оси X — x.

ax.bar(x, values, width=0.6, color='steelblue', edgecolor='navy')

Если по оси X категории (названия), сначала создают числовые позиции, а затем подписывают их:

x = np.arange(len(names))
ax.bar(x, values)
ax.set_xticks(x)
ax.set_xticklabels(names, rotation=45)

1.4. Круговая диаграмма: pie()

Функция pie(values, labels=...) показывает доли от целого. Сумма всех значений принимается за 100%.

ax.pie(hours, labels=labels, autopct='%1.1f%%', startangle=90)
ax.axis('equal')  # чтобы круг не превращался в овал

Параметр autopct выводит проценты на секторах, startangle задаёт угол поворота первого сектора.

1.5. Оформление осей и сохранение

Все настройки применяются к объекту ax:

ax.set_title('Заголовок')
ax.set_xlabel('Подпись оси X')
ax.set_ylabel('Подпись оси Y')
ax.set_xlim(0, 10)
ax.set_ylim(0, 100)
ax.grid(True, linestyle='--', alpha=0.5)
ax.legend(loc='upper left')
ax.axhline(0, color='gray', linestyle='--')   # горизонтальная линия
ax.axvline(5, color='red', linestyle=':')     # вертикальная линия

Сохранение графика в файл:

fig.savefig('plot.png', dpi=150)  # до plt.show()
plt.show()
⚠️
Важно: вызывайте savefig до plt.show(). После показа окна фигура может быть очищена, и файл сохранится пустым.

Пример A1

Среднемесячная температура в Москве

◆ Задание
Построить график температуры за 12 месяцев, подписать оси, включить сетку и сохранить в файл.
Решение
import numpy as np
import matplotlib.pyplot as plt

months = ['Янв','Фев','Мар','Апр','Май','Июн',
          'Июл','Авг','Сен','Окт','Ноя','Дек']
temp = np.array([-6.2, -5.9, -0.2, 7.5, 14.3, 18.1,
                 20.0, 18.0, 12.2, 5.6, -0.9, -5.0])

fig, ax = plt.subplots(figsize=(9, 4.5))
ax.plot(months, temp, color='steelblue', linewidth=2,
        marker='o', markersize=6, label='Москва')

ax.set_title('Среднемесячная температура в Москве')
ax.set_xlabel('Месяц')
ax.set_ylabel('Температура, °C')
ax.grid(True, linestyle='--', alpha=0.6)
ax.legend(loc='upper left')

fig.tight_layout()
fig.savefig('moscow_temp.png', dpi=150)
plt.show()
Пример A2

Свободное падение без сопротивления воздуха

◆ Задание

Тело отпущено с высоты $h_0$ без начальной скорости. Ускорение свободного падения $g \approx 9.81$ м/с².

$$h(t) = h_0 - \tfrac{1}{2} g t^2, \qquad v(t) = g t, \qquad t_{\text{пад}} = \sqrt{\dfrac{2 h_0}{g}}$$

При $h_0 = 100$ м время падения $t_{\text{пад}} \approx 4.52$ с.

Решение
import numpy as np
import matplotlib.pyplot as plt

g  = 9.81
h0 = 100.0

t_fall = np.sqrt(2 * h0 / g)
t = np.linspace(0, t_fall, 200)
h = h0 - 0.5 * g * t**2

fig, ax = plt.subplots(figsize=(9, 4.5))

ax.plot(t, h, color='steelblue', linewidth=2, label='Свободное падение')

ax.set_title(f'Падение с высоты {h0:.0f} м')
ax.set_xlabel('Время, с')
ax.set_ylabel('Высота, м')

ax.set_xlim(0, 5)
ax.set_ylim(0, h0 * 1.05)

ax.grid(True, linestyle='--', alpha=0.6)
ax.spines['left'].set_position('zero')
ax.spines['bottom'].set_position('zero')
ax.spines['top'].set_visible(False)
ax.spines['right'].set_visible(False)
ax.plot(1, 0, '>k', transform=ax.get_yaxis_transform(), clip_on=False)
ax.plot(0, 1, '^k', transform=ax.get_xaxis_transform(), clip_on=False)

ax.legend(loc='upper right')

fig.tight_layout()
fig.savefig('fall_free.png', dpi=150)
plt.show()
Пример A3

Гармонические колебания груза на пружине

◆ Задание

Груз на пружине совершает свободные гармонические колебания вдоль вертикальной оси. Амплитуда колебаний $A = 5$ см, период $T = 2$ с. В начальный момент времени ($t = 0$) груз находится в крайнем верхнем положении.

Начало координат совмещено с положением равновесия груза, ось $x$ направлена вертикально вверх. Сопротивлением среды и затуханием пренебречь.

При гармонических колебаниях координата тела меняется по закону косинуса (или синуса):
$$x(t) = A \cos(\omega t + \varphi_0)$$
где $\omega = \dfrac{2\pi}{T}$ — циклическая частота, $\varphi_0$ — начальная фаза.

Решение
import numpy as np
import matplotlib.pyplot as plt

# параметры колебаний
A = 5.0                          # амплитуда, см
T = 2.0                          # период, с
omega = 2 * np.pi / T            # циклическая частота

t = np.linspace(0, 2 * T, 400)   # два периода
x = A * np.cos(omega * t)        # координата

fig, ax = plt.subplots(figsize=(8, 4.5))

ax.plot(t, x, color='tab:blue', linewidth=2)

# подписи по правилам физики
ax.set_xlabel('t, с')
ax.set_ylabel('x, см')
ax.set_title('Гармонические колебания: $x(t) = A\\\\cos(\\\\omega t)$')

# оси через ноль + стрелки
ax.spines['left'].set_position('zero')
ax.spines['bottom'].set_position('zero')
ax.spines['top'].set_visible(False)
ax.spines['right'].set_visible(False)
ax.plot(1, 0, '>k', transform=ax.get_yaxis_transform(), clip_on=False)
ax.plot(0, 1, '^k', transform=ax.get_xaxis_transform(), clip_on=False)

ax.set_ylim(-A * 1.2, A * 1.2)
ax.grid(True, linestyle=':', alpha=0.6)

plt.tight_layout()
plt.show()
Пример A4

Выручка кофейни за две недели

◆ Задание

Кофейня работает семь дней в неделю. Владелец записывал дневную выручку в течение двух недель подряд. Значения приведены в тыс. руб.:

НеделяПнВтСрЧтПтСбВс
1-я12.511.813.214.118.722.419.8
2-я13.112.414.515.219.823.620.5
Решение
import numpy as np
import matplotlib.pyplot as plt

days    = ['Пн', 'Вт', 'Ср', 'Чт', 'Пт', 'Сб', 'Вс'] * 2
revenue = np.array([12.5, 11.8, 13.2, 14.1, 18.7, 22.4, 19.8,
                    13.1, 12.4, 14.5, 15.2, 19.8, 23.6, 20.5])
x        = np.arange(len(days))
mean_rev = revenue.mean()

fig, ax = plt.subplots(figsize=(11, 4.5))

ax.plot(x, revenue, marker='o', color='steelblue',
        linewidth=2, markersize=7, label='выручка')

ax.axhline(mean_rev, color='gray', linestyle='--', linewidth=1,
           label=f'среднее = {mean_rev:.1f}')

ax.set_title('Выручка кофейни за две недели')
ax.set_xlabel('День недели')
ax.set_ylabel('Выручка, тыс. руб.')
ax.set_xlim(-0.5, 13.5)
ax.set_ylim(5, 30)
ax.set_xticks(x)
ax.set_xticklabels(days, rotation=45)
ax.grid(True, linestyle='--', alpha=0.5)
ax.legend(loc='upper left')

fig.tight_layout()
fig.savefig('coffee.png', dpi=150)
plt.show()
