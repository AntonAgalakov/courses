Раздел 01

Цель работы и правила оформления

Как читать блок-схемы и оформлять код модуля

1.1. Цель лабораторной работы

Научиться читать алгоритмы, представленные в виде блок-схем, корректно переносить ветвления, циклы и граничные условия в функции на языке Python, а также оформлять набор функций в виде самостоятельного подключаемого модуля.

1.2. Обозначения элементов на блок-схемах

Фигура Назначение Соответствие в Python
Овал (терминатор) Начало функции с входными параметрами или выход с возвратом значения def func(...): / return ...
Прямоугольник Вычислительный процесс, присваивание или обновление переменных x = 0, i = i + 1
Ромб Проверка логического условия (ветвление «Да» / «Нет») if ...: / else: / while ...:
Стрелки Направление потока управления; возврат стрелки вверх образует цикл while условие: ...

1.3. Обязательные требования к реализации

  1. Все функции должны находиться в одном файле-модуле algorithms.py и иметь строго заданные имена и параметры.
  2. Логика каждой функции должна воспроизводить алгоритм с блок-схемы (нельзя заменять алгоритм готовыми библиотечными функциями вроде math.gcd, math.sqrt или срезом [::-1]).
  3. Каждая функция должна содержать краткую строку документации (docstring), описывающую её назначение и параметры.
  4. В модуле algorithms.py не должно быть «висящих» вызовов input() или print() на верхнем уровне — при импорте модуль должен загружаться молча.

Функция 01

Разворот цифр числа

Уровень: базовый
Сигнатура функции
def reverse_number(n):

Описание задачи: функция принимает неотрицательное целое число n и возвращает новое целое число, полученное записью цифр исходного числа в обратном порядке.

Принцип работы: создаётся аккумулятор rev = 0. Пока n > 0, на каждом шаге извлекается последняя цифра (n % 10), дописывается в конец нового числа (rev * 10 + digit), а последний разряд исходного числа отбрасывается (n // 10).

Входные данные
n: int — целое число (n >= 0)
Возвращаемое значение
int — число с обратным порядком цифр
💡
Граничные случаи: при n = 0 цикл не выполняется и возвращается 0; при n = 1200 ведущие нули отбрасываются и возвращается 21.
Блок-схема алгоритмаreverse_number
Функция 02

Наибольший общий делитель (алгоритм Евклида)

Уровень: базовый
Сигнатура функции
def gcd(a, b):

Описание задачи: функция вычисляет наибольший общий делитель (НОД) двух целых неотрицательных чисел a и b.

Принцип работы: используется свойство НОД(a, b) = НОД(b, a % b). Пока b != 0, значение b сохраняется во временную переменную temp, новое b становится равным остатку от деления a % b, а a получает прежнее значение b.

Входные данные
a: int, b: int — целые неотрицательные числа
Возвращаемое значение
int — наибольший общий делитель
💡
Граничные случаи: если одно из чисел равно 0 (например, gcd(10, 0) или gcd(0, 7)), функция возвращает второе число.
Блок-схема алгоритмаgcd
Функция 03

Проверка числа на простоту

Уровень: базовый
Сигнатура функции
def is_prime(n):

Описание задачи: функция определяет, является ли целое число n простым (имеет ровно два натуральных делителя: 1 и само себя), и возвращает True или False.

Принцип работы: сначала отсекаются числа n <= 1. Затем проверяются возможные делители d начиная с 2, пока d * d <= n. Если n % d == 0, число составное — возвращается False.

Входные данные
n: int — произвольное целое число
Возвращаемое значение
bool — True, если простое, иначе False
💡
Граничные случаи: числа -3, 0, 1 дают False; число 2 является наименьшим простым числом (True).
Блок-схема алгоритмаis_prime
Функция 04

N-е число Фибоначчи

Уровень: средний
Сигнатура функции
def fibonacci(n):

Описание задачи: функция вычисляет n-е число Фибоначчи для целого n >= 0, где последовательность начинается с 0, 1, 1, 2, 3, 5, 8....

Принцип работы: при n == 0 возвращается 0. Иначе задаются два соседних члена prev = 0, curr = 1 и счётчик i = 1. Пока i < n, вычисляется nxt = prev + curr, после чего значения сдвигаются вперёд.

Входные данные
n: int — индекс элемента (n >= 0)
Возвращаемое значение
int — n-е число Фибоначчи
💡
Граничные случаи: при n = 0 возвращается 0; при n = 1 цикл не выполняется ни разу и возвращается 1.
Блок-схема алгоритмаfibonacci
Функция 05

Наибольшая последовательность возрастающих элементов

Уровень: средний
Сигнатура функции
def max_increasing_len(arr):

Описание задачи: функция принимает список чисел arr и находит максимальную длину непрерывного строго возрастающего подотрезка (arr[i] > arr[i - 1]).

Принцип работы: если список пуст, возвращается 0. Иначе задаются cur = 1, best = 1 и индекс i = 1. При росте элемента cur увеличивается на 1, при нарушении возрастания сбрасывается в 1. На каждом шаге обновляется best = max(best, cur).

Входные данные
arr: list — список чисел
Возвращаемое значение
int — максимальная длина возрастающего участка
💡
Граничные случаи: пустой список даёт 0; список из одного элемента или строго убывающий список возвращает 1.
Блок-схема алгоритмаmax_increasing_len
Функция 06

Квадратный корень методом Ньютона (Герона)

Уровень: средний
Сигнатура функции
def sqrt_newton(n, eps=1e-6):

Описание задачи: функция приближённо вычисляет квадратный корень из неотрицательного числа n с заданной точностью eps.

Принцип работы: при n == 0 сразу возвращается 0.0. Иначе берётся начальное приближение x = n / 2, и пока погрешность |x * x - n| > eps, приближение уточняется по итерационной формуле Герона x = 0.5 * (x + n / x).

Входные данные
n: float (n >= 0), eps: float (eps > 0)
Возвращаемое значение
float — приближённое значение √n
💡
Граничные случаи: случай n == 0 обрабатывается отдельной веткой до входа в цикл, чтобы избежать деления на ноль.
Блок-схема алгоритмаsqrt_newton
Функция 07

Поиск второго максимума

Уровень: повышенный
Сигнатура функции
def second_max(arr):

Описание задачи: функция принимает список чисел arr и возвращает второй по величине элемент среди различных значений списка.

Принцип работы: если в списке меньше двух элементов, возвращается None. Иначе заводятся два лидера m1 = -inf и m2 = -inf. Если arr[i] > m1, бывший лидер переходит в m2, а m1 обновляется; если m2 < arr[i] < m1, обновляется m2.

Входные данные
arr: list — список чисел
Возвращаемое значение
второй максимум или None (или -inf при отсутствии второго уникального)
💡
Подсказка: в Python отрицательную бесконечность можно задать как float("-inf") — это позволяет корректно обрабатывать списки отрицательных чисел.
Блок-схема алгоритмаsecond_max
Функция 08

Количество простых чисел в диапазоне от 2 до N

Уровень: повышенный
Сигнатура функции
def count_primes_up_to(n):

Описание задачи: функция подсчитывает, сколько простых чисел содержится в диапазоне от 2 до целого числа n включительно.

Принцип работы: внешний цикл перебирает кандидатов num от 2 до n. Для каждого числа выставляется флаг is_p = True, а внутренний цикл ищет делители d до d * d <= num. Если делитель не найден (is_p == True), счётчик cnt увеличивается на 1.

Входные данные
n: int — верхняя граница диапазона
Возвращаемое значение
int — количество простых чисел на отрезке [2, n]
⚠️
Обратите внимание: реализуйте алгоритм строго по вложенной блок-схеме (без вызова вашей функции is_prime внутри).
