Раздел 01

Теоретический материал

Всё, что нужно знать, чтобы оживить любой график

1.1. Что такое анимация в Matplotlib

Анимация — это последовательность кадров (frames), которая быстро сменяет друг друга. Каждый кадр — это тот же график, у которого поменялись данные или оформление. Если кадры показывать с частотой ≥ 20 кадров в секунду, глаз воспринимает их как плавное движение.

Matplotlib не создаёт видео сам по себе — он умеет перерисовывать график. Анимация строится на трёх китах:

  • Figure — окно, в котором живёт картинка;
  • Artist — объекты внутри (линия, точка, столбик), у которых можно менять свойства;
  • Функция-обработчик — вызывается для каждого кадра и обновляет объекты.
💡
Главная идея: анимация в Matplotlib — это цикл «вычислить новые данные → положить их в Artist → перерисовать экран». Всё остальное — детали.

1.2. Основной инструмент: FuncAnimation

Модуль matplotlib.animation содержит класс FuncAnimation — именно он связывает вашу функцию-обработчик с циклом покадровой отрисовки.

from matplotlib.animation import FuncAnimation

ani = FuncAnimation(
    fig,              # Figure, где рисуем
    update,           # функция: вызывается для каждого кадра
    frames=200,       # сколько кадров (число или итерируемый объект)
    interval=40,      # пауза между кадрами в миллисекундах
    repeat=False,     # повторять ли анимацию после конца
)

Минимальный рабочий пример:

import numpy as np
import matplotlib.pyplot as plt
from matplotlib.animation import FuncAnimation

fig, ax = plt.subplots()
ax.set_xlim(0, 100)
ax.set_ylim(0, 10)

dot, = ax.plot([], [], 'ro', ms=12)   # пустая точка — заготовка

def update(frame):
    dot.set_data([frame], [5])         # точка едет по горизонтали
    return dot,

ani = FuncAnimation(fig, update, frames=100, interval=40)
plt.show()

Что здесь важно понять:

  • frame — целое число: 0, 1, 2, …, 99. Обычно его делят на что-то для плавности (frame / 10);
  • точка создаётся один раз с пустыми данными (plot([], [])), а потом мы только подменяем её координаты через set_data;
  • interval — сколько миллисекунд ждать между кадрами. 40 мс = 25 кадров/с;
  • объект ani нужно сохранить в переменную, иначе Python удалит его сборщиком мусора и анимация «умрёт».

1.2.1. Зачем запятая в dot, = ax.plot(...)

Это классическая ловушка, на которой спотыкаются почти все. Разберёмся один раз — и навсегда.

ax.plot() всегда возвращает список объектов Line2D — даже если вы нарисовали одну-единственную линию. Запятая после имени — это распаковка (tuple unpacking): она достаёт единственный элемент из списка.

result = ax.plot([1, 2, 3], [4, 5, 6])
print(type(result))   # <class 'list'>
print(len(result))    # 1 — в списке один элемент

# Без запятой — в переменной список, а не линия:
dot = ax.plot([], [], 'ro')        # dot — это [<Line2D>]
# dot.set_data(...)                # ❌ AttributeError: 'list' object has no attribute 'set_data'

# С запятой — распаковка:
dot, = ax.plot([], [], 'ro')       # dot — это <Line2D>
dot.set_data([0], [5])             # ✅

# Эквивалентные варианты (все дают один и тот же <Line2D>):
dot = ax.plot([], [], 'ro')[0]     # взять по индексу
[dot] = ax.plot([], [], 'ro')      # явная распаковка

Почему так? ax.plot() спроектирован для рисования нескольких линий за один вызов:

ax.plot(x, y1, x, y2)              # две линии → список из двух Line2D
l1, l2 = ax.plot(x, y1, x, y2)     # распаковка в две переменные (без хвостовой запятой)

Именно поэтому возвращается список: чтобы можно было нарисовать хоть одну линию, хоть десять. А запятая — это способ «вытащить» единственный элемент из этого списка.

КодЧто в переменнойРаботает?
dot = ax.plot(...)[<Line2D>]❌ dot.set_data() — ошибка
dot = ax.plot(...)[0]<Line2D>✅
dot, = ax.plot(...)<Line2D>✅ (идиоматично)
l1, l2 = ax.plot(x, y1, x, y2)два <Line2D>✅
lines = ax.plot(x, y1, x, y2)[<Line2D>, <Line2D>]✅ (но lines[0].set_data(...))
💡
Правило: одна линия → line, = ax.plot(...). Две линии → l1, l2 = ax.plot(x, y1, x, y2) (без хвостовой запятой).
🎯
Аналогия для студентов: ax.plot() — это конвейер, который всегда выдаёт коробку, даже если в ней одна конфета. Запятая dot, = — это «достать конфету из коробки». Без неё у вас в руках коробка, а не конфета, и «съесть» её (вызвать set_data) нельзя.

1.3. Функция update: сердце анимации

Функция-обработчик принимает один аргумент — номер кадра — и возвращает Artist(ы), которые нужно перерисовать. Внутри неё меняются данные или свойства.

Простейшие операции внутри update:

МетодЧто меняетПример
line.set_data(x, y)координаты линииline.set_data(x[:n], y[:n])
dot.set_data([x], [y])координаты одной точкиdot.set_data([t], [np.sin(t)])
line.set_color('red')цветline.set_color('tab:blue')
dot.set_markersize(20)размер маркераdot.set_markersize(10)
bar.set_height(h)высота столбикаbar.set_height(42)
ax.set_xlim(a, b)предел оси Xax.set_xlim(0, 10)

Правило: set_data принимает списки или массивы, даже если точка одна. Пишите dot.set_data([x], [y]), а не dot.set_data(x, y).

1.4. Как «рисовать по кусочкам»: накопление через срез

Самый частый приём: у нас есть готовый массив x и y, и мы хотим, чтобы линия «прорисовывалась» от первого значения к последнему. Для этого в каждом кадре передаём в set_data только первые n точек:

def update(frame):
    n = frame + 1                         # сколько точек показать
    line.set_data(x[:n], y[:n])           # ← срез!
    return line,

Это работает для любой кривой: синусоиды, параболы, сердца, спирографа. Меняется только формула для x и y.

  • frame=0 → n=1 → видна одна точка;
  • frame=99 → n=100 → видна вся кривая.

1.5. Динамические данные: append вместо готового массива

Если формула «зависит от предыдущего шага» (например, случайное блуждание), массив нужно дописывать на каждом кадре:

xs, ys = [0], [0]

def update(frame):
    xs.append(xs[-1] + np.random.uniform(-1, 1))
    ys.append(ys[-1] + np.random.uniform(-1, 1))
    line.set_data(xs, ys)
    ax.set_xlim(min(xs) - 1, max(xs) + 1)   # авто-масштаб
    ax.set_ylim(min(ys) - 1, max(ys) + 1)
    return line,

Чтобы график не «убегал» за край, обновляйте set_xlim / set_ylim прямо в update.

1.6. Остановка анимации: два способа

Способ A — заранее известно число кадров. Просто передайте frames=N. Анимация пройдёт N кадров и остановится (если repeat=False):

ani = FuncAnimation(fig, update, frames=200, interval=40, repeat=False)

Способ B — условие проверяется внутри update. Вызываем ani.event_source.stop():

def update(frame):
    ...
    if condition_met:
        dot.set_color('red')
        ani.event_source.stop()       # ← остановка «изнутри»
    return dot,

ani = FuncAnimation(fig, update, frames=1000, interval=40)
⚠️
Важно: переменная ani должна существовать к моменту первого вызова update. Создавайте ani = FuncAnimation(...) после определения функции, и Python найдёт её.

Способ A проще, когда ответ известен из математики (например, «когда T = 40°C»). Способ B гибче — условие может зависеть от данных.

1.7. Параметр repeat и повторный показ

По умолчанию repeat=True — анимация зацикливается. Для «научных» анимаций, где важен результат, ставьте repeat=False, иначе после остановки всё начнётся заново.

ani = FuncAnimation(fig, update, frames=300, interval=40, repeat=False)

Отдельно можно управлять паузой после последнего кадра: repeat_delay=2000 (2 секунды паузы перед повтором).

1.8. Параметр blit: что это и зачем

blit=True — режим «перерисовывать только изменившиеся объекты». Ускоряет анимацию с большим числом точек, но требует двух условий:

  1. update должен возвращать кортеж обновлённых Artist-ов: return line, dot (с запятой!);
  2. все объекты должны быть созданы до запуска анимации.

Если blit=False (по умолчанию), можно писать проще:

def update(frame):
    line.set_data(x, y)
    # return не нужен

ani = FuncAnimation(fig, update, frames=200, interval=40)
РежимКогда использоватьВозврат из update
blit=Trueмного точек, сложная графика — нужна скоростьreturn line, dot
blit=Falseучебные примеры, мало объектовможно без return
💡
Для начала не используйте blit — код проще. Добавите позже, когда анимация начнёт подтормаживать.

1.9. init_func: зачем нужна «пустая» функция

init_func — необязательная функция, которая вызывается один раз перед первым кадром и задаёт «чистое» состояние. Нужна только при blit=True. Для учебных задач её можно не писать:

# С init_func (если нужен blit=True и контроль 1-го кадра)
def init():
    line.set_data([], [])
    return line,

ani = FuncAnimation(fig, update, frames=200, interval=40,
                    init_func=init, blit=True)

# Без init_func — короче
ani = FuncAnimation(fig, update, frames=200, interval=40)

1.10. Сохранение и просмотр: Jupyter, GIF, MP4

В Jupyter/Colab plt.show() не покажет анимацию — нужно обернуть в HTML:

from IPython.display import HTML
HTML(ani.to_jshtml())

Сохранить в GIF (нужен pillow):

ani.save('animation.gif', writer='pillow', fps=25)

Сохранить в MP4 (нужен ffmpeg):

ani.save('animation.mp4', writer='ffmpeg', fps=25)

По кадрам — если нужен ручной контроль:

for i, frame in enumerate(range(0, 200, 10)):
    update(frame)
    fig.savefig(f'frame_{i:03d}.png')
⚠️
При save() Matplotlib предупредит, что FuncAnimation не сохранён. Игнорируйте — это лишь рекомендация добавить plt.show() в конец.

1.11. Чек-лист: как построить любую анимацию

  1. Подготовить данные. Либо готовые массивы x и y (для «рисования по кусочкам»), либо стартовые значения (для «динамики»).
  2. Создать Artist. line, = ax.plot([], []) — пустая линия; dot, = ax.plot([], [], 'ro') — пустая точка; bars = ax.bar(...) — столбики.
  3. Настроить оси. ax.set_xlim, ax.set_ylim. Если данные растут — обновлять в update.
  4. Написать update. Один аргумент frame. Внутри — set_data / set_color / append.
  5. Создать FuncAnimation. frames=N, interval=40, repeat=False.
  6. Запустить. plt.show() или HTML(ani.to_jshtml()).

Пример A2

Синусоида рисуется по кусочкам

Что разбираем: главный приём всех заданий — показывать первые n точек готового массива через срез.

Решение
import numpy as np
import matplotlib.pyplot as plt
from matplotlib.animation import FuncAnimation

x = np.linspace(0, 4 * np.pi, 200)
y = np.sin(x)

fig, ax = plt.subplots(figsize=(9, 3))
ax.set_xlim(0, 4 * np.pi)
ax.set_ylim(-1.2, 1.2)

line, = ax.plot([], [], 'b-', lw=2)
dot,  = ax.plot([], [], 'ro', ms=8)

def update(frame):
    n = frame + 1
    line.set_data(x[:n], y[:n])         # ← срез
    dot.set_data([x[n-1]], [y[n-1]])
    return line, dot

ani = FuncAnimation(fig, update, frames=len(x), interval=30)
plt.show()
Пример A3

Две волны на одном графике

Что разбираем: update обновляет сразу несколько объектов и возвращает их кортежем.

Решение
import numpy as np
import matplotlib.pyplot as plt
from matplotlib.animation import FuncAnimation

x = np.linspace(0, 4 * np.pi, 300)

fig, ax = plt.subplots(figsize=(9, 3.5))
ax.set_xlim(0, 4 * np.pi)
ax.set_ylim(-1.5, 1.5)

sin_line, = ax.plot([], [], 'b-', lw=2, label='sin')
cos_line, = ax.plot([], [], 'r-', lw=2, label='cos')
ax.legend()

def update(frame):
    t = frame / 10
    sin_line.set_data(x, np.sin(x - t))
    cos_line.set_data(x, np.cos(x - t))
    return sin_line, cos_line

ani = FuncAnimation(fig, update, frames=300, interval=30)
plt.show()
Пример A4

Остановка по условию

Что разбираем: как остановить анимацию «изнутри» через ani.event_source.stop().

Решение
import matplotlib.pyplot as plt
from matplotlib.animation import FuncAnimation

fig, ax = plt.subplots(figsize=(8, 3))
ax.set_xlim(0, 100)
ax.set_ylim(0, 10)

dot, = ax.plot([], [], 'ro', ms=15)

def update(frame):
    dot.set_data([frame], [5])
    if frame >= 80:
        dot.set_color('green')
        dot.set_markersize(22)
        ani.event_source.stop()        # ← стоп
    return dot,

ani = FuncAnimation(fig, update, frames=200, interval=40)
plt.show()
