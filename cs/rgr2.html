Раздел 00

Исходные данные и допущения

Файл movie.txt можно скачать по кнопке в разделе «Формат файла».

Файл подготовлен на основе открытого датасета IMDb movies dataset (85 855 фильмов). В него включены только те записи, у которых заполнены все поля, поэтому пропусков в данных нет.

Принятые допущения

  1. Данные считаются достоверными в рамках выданного файла. Все выводы формулируются как «в рамках данного файла», а не как универсальные утверждения о киноиндустрии.
  2. Разделитель полей — точка с запятой ;. Первая строка файла — заголовок с названиями столбцов.
  3. Пропусков в данных нет: каждое поле в каждой строке заполнено. Все числовые столбцы корректно преобразуются в int / float без дополнительных проверок.
  4. В файле представлены только фильмы (значение type = movie), потому что исходный датасет IMDb movies dataset содержит только фильмы.
  5. Единицы измерения: рейтинг IMDb — шкала 0–10; год — целое число; длительность — минуты; бюджет и кассовые сборы — доллары США.
  6. Выбросы не удаляются, но при необходимости оговариваются в отчёте.
  7. Файл не изменяется — все преобразования выполняются в коде на Python.

Раздел 02

Задание

Три части. Выполняются последовательно, каждая опирается на предыдущую.

◆ Условие · Часть 1

Чтение файла и первичный осмотр.

  1. Откройте файл movie.txt через open() в режиме чтения. Прочитайте все строки.
  2. Отделите первую строку (заголовок) и разбейте её по ; — получите список названий столбцов.
  3. Каждую строку данных разбейте по ;. Преобразуйте числовые поля (year, votes, duration, budget, gross, rating) в int / float.
  4. Выведите на экран:
    • число строк данных (без заголовка);
    • названия столбцов;
    • первые 5 записей в читаемом виде;
    • минимальный и максимальный год выпуска среди записей.
  5. Сделайте вывод: какие столбцы пригодны для визуализации и какие из них лучше подходят для гистограммы, столбчатой диаграммы и диаграммы рассеяния.

Требования к оформлению: в отчёте привести скриншот вывода консоли и фрагмент исходного txt-файла.

◆ Условие · Часть 2

Базовые графики.

Постройте три отдельных графика (можно в одном окне через subplots(1, 3)):

  1. Гистограмма распределения рейтингов.
    • Подписи осей: «Рейтинг IMDb», «Количество фильмов».
    • Заголовок: «Распределение рейтингов».
    • Сетка по оси Y.
  2. Столбчатая диаграмма топ-10 жанров по количеству фильмов.
    • Горизонтальные бары (barh), отсортированные по убыванию.
    • Подпись оси X: «Количество фильмов».
  3. Круговая диаграмма распределения фильмов по жанрам (топ-5 жанров + категория «Другие»).
    • Подписи долей в процентах (autopct='%1.1f%%').
    • Заголовок: «Доли жанров».

Требования к оформлению: у каждого графика — заголовок, подписи осей (если применимо), легенда (для круговой — не обязательна). Цвета должны различаться.

◆ Условие · Часть 3

Сравнение по годам.

  1. Постройте линейный график среднего рейтинга фильмов по годам выпуска (с 1990 года).
    • Ось X — год, ось Y — средний рейтинг.
    • Добавьте plt.grid(True).
    • Подписи осей и заголовок графика.
  2. Найдите год с максимальным средним рейтингом и отметьте эту точку на графике с помощью plt.annotate(): подпишите год и значение рейтинга.
  3. Добавьте горизонтальную линию общего среднего рейтинга по всем фильмам (axhline) и подпишите её значение.
  4. Сделайте вывод: в каком году средний рейтинг был максимальным; выше или ниже этот пик общего среднего.

Подсказка: средние по годам считаются вручную — соберите рейтинги в словарь {год: [список рейтингов]} и усредните.
