Урок #3: Циклы в Python (while)

Научитесь повторять действия с помощью цикла while — основного инструмента для создания игр, симуляций и интерактивных программ!

📚 Цикл while

Цикл while выполняет блок кода пока условие истинно. Как только условие становится ложным — цикл останавливается.

count = 0
while count < 3:
    print("Привет!")
    count = count + 1

Выведет "Привет!" три раза. Обратите внимание: переменная count обязательно должна изменяться внутри цикла!

⚠️ Осторожно! Если забыть изменить переменную в теле цикла, получится бесконечный цикл — программа зависнет!

# ПЛОХО! Бесконечный цикл:
while True:
    print("Помогите!")  # Никогда не остановится

🐍 Интересный факт

Цикл while — один из самых древних управляющих конструкций в программировании. Он позволяет реализовать любую логику повторения, даже если заранее неизвестно, сколько раз нужно повторить действие.

💡 Советы по циклу while

  • Всегда проверяйте, что условие цикла рано или поздно станет False.
  • Используйте break, чтобы досрочно выйти из цикла (например, при вводе "стоп").
  • Используйте continue, чтобы пропустить остаток текущей итерации и перейти к проверке условия.

Задача 5: Последовательность Сиракуэз (Гипотеза Коллатца)

  • Если число четное, делим его на 2.

Программа должна выводить все числа последовательности и их длину (количество шагов до единицы).

Пример для числа 6: 6 → 3 → 10 → 5 → 16 → 8 → 4 → 2 → 1. Длина: 9 шагов.

Задача 8 🏆: Симулятор спортивного комментатора

Программа симулирует матч между двумя командами. Счет начинается с 0:0. В цикле с каждой итерацией ("минутой матча") с небольшой вероятностью забивает одна из команд. Цикл длится, пока не истекут "90 минут" или пока не будет забито 5 голов. После каждого гола программа выводит текущий счет и "имя забившего" (случайным образом выбранное из списка).

Пример работы:

Минута 7: Гол! Счёт 1:0. Забил: Иванов!
Минута 23: Гол! Счёт 1:1. Забил: Петров!
Минута 45: Гол! Счёт 2:1. Забил: Сидоров!

Минута 82: Гол! Счёт 3:2. Забил: Васильев!
Матч завершён! Итоговый счёт: 3:2

Подсказка: используйте random.random() < 0.05 для 5% шанса гола на каждой минуте.

🐢 Дополнительно: Библиотека Turtle

Знакомство с Черепахой

Библиотека turtle позволяет рисовать фигуры с помощью виртуальной черепашки. Циклы while здесь незаменимы для создания узоров и сложных фигур.

В учебных задачах (ОГЭ/ЕГЭ) удобно подключать все команды сразу через from turtle import * — тогда можно писать forward(...) вместо t.forward(...).

from turtle import *
from random import seed

seed(5)             # Фиксируем "случайность" (для воспроизводимости)

speed(5)            # Скорость (1-10, 0 - мгновенно)

forward(100)        # Вперёд на 100 пикселей
right(90)           # Повернуть направо на 90 градусов
left(45)            # Повернуть налево на 45 градусов
penup()             # Поднять перо (не рисовать)
pendown()           # Опустить перо
color("red")        # Цвет линии

Важное правило геометрии: Сумма всех внешних углов любой замкнутой фигуры всегда равна 360°. Если черепашка поворачивает направо на 90°, ей понадобится 4 шага, чтобы сделать круг (4 × 90 = 360).

Задача 9: Turtle: Растущая спираль

Нарисуйте спираль. Черепашка начинает с шага 10, поворачивает направо на 90° и идёт вперёд. С каждым шагом длина увеличивается на 5. Цикл идёт, пока длина шага меньше 200.

step = 10
while step < 200:
    forward(step)
    right(90)
    step = step + 5

Усложнение: Попробуйте изменить угол поворота на 60° или 45°. Как изменится узор?

Задача 10: Turtle: Мандала (Вложенные циклы)

Нарисуйте красивую мандалу с помощью двух циклов while. Внешний цикл рисует 12 лепестков (поворот на 30° после каждого). Внутренний цикл рисует сам лепесток (например, 30 коротких шагов с поворотом на 6°).

i = 0
while i < 12:
    j = 0
    while j < 30:
        forward(3)
        right(6)
        j = j + 1
    right(30)  # Поворот для нового лепестка
    i = i + 1

Задача 9 🏆: 🍀 Счастливые и несчастливые числа

Число называется счастливым, если, повторяя операцию «заменить число суммой квадратов его цифр», мы рано или поздно получим 1. Если же процесс зацикливается на последовательности 4 → 16 → 37 → 58 → 89 → 145 → 42 → 20 → 4 → …, число несчастливое.

Напишите программу, которая принимает натуральное число N, выводит всю цепочку преобразований через « → » и в конце сообщает вердикт.

Пример для 19:
19 → 82 → 68 → 100 → 1 — счастливое число 🍀

Пример для 4:
4 → 16 → 37 → 58 → 89 → 145 → 42 → 20 → 4 — несчастливое число 😢

Подсказка: для разбора числа на цифры используйте % 10 (последняя цифра) и // 10 (отбросить последнюю цифру) во вложенном цикле while.
