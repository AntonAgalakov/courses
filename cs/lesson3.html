текстовой информации

Практическое изучение Unicode, UTF-8, CP1251 и инструментов Python для работы с байтами

1 Цель работы

Изучить принципы кодирования символов, освоить основные функции Python для работы с символами и байтами (ord, chr, encode, decode), получить практические навыки преобразования текста между различными кодировками и анализа ошибок интерпретации данных (mojibake).

2 Теоретические сведения
Основные операции в Python:
# 1. Получить числовой код символа
print(ord('A'))          # Вывод: 65

# 2. Получить символ по коду
print(chr(65))           # Вывод: A

# 3. Кодирование строки в байты
print('Привет'.encode('utf-8'))  
# Вывод: b'\xd0\x9f\xd1\x80\xd0\xb8\xd0\xb2\xd0\xb5\xd1\x82'

# 4. Декодирование байтов в строку
print(b'\xd0\x9f\xd1\x80'.decode('utf-8')) 
# Вывод: Пр

# 5. Определение длины (символы vs байты)
print(len('Привет'))                     # Вывод: 6
print(len(b'\xd0\x9f\xd1\x80\xd0\xb8\xd0\xb2\xd0\xb5\xd1\x82')) # Вывод: 12
Важно: Префикс b перед строкой (например, b'...') означает, что это объект типа bytes (байты), а не текстовая строка str. Запись \xd0 представляет один байт в шестнадцатеричной системе счисления.
