Раздел 01

Списки в Python

Что такое список, как обращаться к элементам, перебирать их и хранить вложенные структуры

1.1. Что такое список

Список (list) — упорядоченная, изменяемая коллекция элементов. Можно представить его как контейнер, в котором хранятся объекты в определённом порядке. Элементы могут быть разных типов.

fruits = ["яблоко", "банан", "вишня"]
mixed = [1, "два", 3.14, True]
ℹ️
Список изменяем. В отличие от строки, элемент можно заменить: fruits[0] = "груша".

1.2. Создание списка

empty = []                      # пустой список
nums = [1, 2, 3, 4, 5]          # числа
words = list("abc")             # ['a', 'b', 'c']
zeros = [0] * 5                 # [0, 0, 0, 0, 0]
rng = list(range(5))            # [0, 1, 2, 3, 4]

1.3. Индексы и срезы

Нумерация начинается с нуля. Отрицательные индексы считают с конца.

010-5
120-4
230-3
340-2
450-1
a = [10, 20, 30, 40, 50]
print(a[0])       # 10
print(a[-1])      # 50
print(a[1:4])     # [20, 30, 40]
print(a[:3])      # [10, 20, 30]
print(a[3:])      # [40, 50]
print(a[::2])     # [10, 30, 50]
print(a[::-1])    # [50, 40, 30, 20, 10]
💡
Правая граница среза не включается, как и в range().

1.4. Длина и проверки

a = [1, 2, 3]
print(len(a))       # 3
print(2 in a)       # True
print(5 not in a)   # True

1.5. Перебор списка

for x in [10, 20, 30]:
    print(x)

for i in range(len(a)):
    print(i, a[i])

for i, x in enumerate(a, start=1):
    print(i, x)

1.6. Вложенные списки

Элементом списка может быть другой список — получается «список списков» или матрица.

matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
print(matrix[0])       # [1, 2, 3]
print(matrix[1][2])    # 6

lst = [[1, 2, ['Ok!', 3]], ['list', 4], 5]
print(lst[0][2][0])    # Ok!

1.7. Типичные ошибки

  • IndexError: обращение к несуществующему индексу.
  • Ссылка, а не копия: b = a — это тот же список. Нужна копия — b = a.copy() или b = a[:].
  • Изменение списка прямо во время перебора — можно пропустить элементы.
  • Забыли, что .append() ничего не возвращает (возвращает None).

2.4. Сортировка и разворот

a = [3, 1, 4, 1, 5, 9, 2]

2.6. Три шаблона работы со списками

# [2, 4]

Преобразование: получить новый список из старого.

squares = []
for x in range(5):
    squares.append(x ** 2)
# [0, 1, 4, 9, 16]

a = [1, -2, 3, -4]
for i in range(len(a)):

Задание E

Карта сокровищ

Ты — искатель сокровищ, и у тебя есть карта в виде списка целых чисел. Каждое число — это глубина залегания клада в определённой точке острова.

depths = [1, 3, 2, 5, 4, 6, 1]

Настоящее сокровище находится только в тех позициях, которые удовлетворяют двум условиям:

  1. Позиция не является крайней (то есть не первый и не последний элемент списка).
  2. Значение в этой позиции строго больше обоих своих соседей.

Ваша задача:

  1. Найдите все индексы настоящих сокровищ.
  2. Среди значений в этих позициях определите самое большое (самое глубокое сокровище).
  3. Удалите из исходного списка depths первое вхождение этого максимального значения (не по индексу сокровища, а просто первое вхождение числа в списке!).
  4. Выведите получившийся список.

Пример разбора

Исходный список: depths = [1, 3, 2, 5, 4, 6, 1]

Проверка элементов (кроме крайних):
1. Индекс 1: 3 > 1 и 3 > 2 → сокровище.
2. Индекс 2: 2 < 3 или 2 < 5 → не сокровище.
3. Индекс 3: 5 > 2 и 5 > 4 → сокровище.
4. Индекс 4: 4 < 5 или 4 < 6 → не сокровище.
5. Индекс 5: 6 > 4 и 6 > 1 → сокровище.

Сокровища на индексах 1, 3, 5 со значениями 3, 5, 6.
Самое глубокое — 6.
Удаляем первое вхождение числа 6 из списка:
[1, 3, 2, 5, 4, 1] — это и есть ответ.
⚠️
Особые случаи. Если настоящих сокровищ нет — ничего не удаляйте, выведите исходный список. Если самое глубокое сокровище встречается несколько раз — удалите только первое его вхождение в списке.
Задание F

Алгоритм Луна

Алгоритм Луна (англ. Luhn algorithm), также известный как алгоритм «модуля 10» или «mod 10» — алгоритм вычисления контрольной цифры номера пластиковой карты в соответствии со стандартом ISO/IEC 7812. Назван в честь его создателя, учёного из IBM Ханса Питера Луна. Алгоритм описан в 1954 году, патент получен в 1960 году.

Сам алгоритм не является криптографическим средством, а предназначен в первую очередь для выявления ошибок, вызванных непреднамеренным искажением данных (например, при ручном вводе номера карты, при приёме данных о номере социального страхования по телефону). Позволяет лишь с некоторой степенью достоверности судить об отсутствии ошибок в блоке цифр, но не даёт возможности нахождения и исправления обнаруженной неточности.

Напишите программу для проверки номера банковской карты по алгоритму Луна (необходимо просуммировать все чётные по номеру цифры последовательности, далее прибавить к сумме все нечётные по номеру цифры, помноженные на 2, при этом если произведение получается больше 9, то из него вычитается 9. Сумма должна быть кратной 10).

Задание G

Аббревиатура

Иногда некоторые слова вроде «localization» или «internationalization» настолько длинны, что их весьма утомительно писать много раз в каком-либо тексте.

Будем считать слово слишком длинным, если его длина строго больше 10 символов. Все слишком длинные слова можно заменить специальной аббревиатурой. Эта аббревиатура строится следующим образом: записывается первая и последняя буква слова, а между ними — количество букв между первой и последней буквой (в десятичной системе счисления и без ведущих нулей).

Таким образом, «localization» запишется как «l10n», а «internationalization» как «i18n».

Вам предлагается автоматизировать процесс замены слов на аббревиатуры. При этом все слишком длинные слова должны быть заменены аббревиатурой, а слова, не являющиеся слишком длинными, должны остаться без изменений.

«Грязные» данные: очистка оценок студентов

Вы работаете аналитиком данных в деканате. Из электронного журнала выгрузили список оценок студентов — но выгрузка оказалась «грязной»: где-то лишние пробелы, где-то вместо цифры написано слово («отл», «хор»), где-то пустые строки, а иногда попадаются совсем некорректные значения вроде «100» или «два».

Такая ситуация — типичная для реальной работы аналитика (Data Science): прежде чем считать статистику, данные нужно очистить и нормализовать.

Вам дан «грязный» список строк. В нём могут встречаться:

  • пустые строки и строки с пробелами по краям;
  • числа в виде строк: " 5 ", "4";
  • словесные обозначения: "отл", "хор", "уд", "неуд";
  • отметки "неявка", "н";
  • некорректные значения: "100", "два".
◆ Задание
Напишите программу, которая очищает список оценок и возвращает новый список, отсортированный по убыванию. Правила обработки:
  1. Убрать пробелы по краям каждой строки.
  2. Привести всё к числовому виду: "5", "отл" → 5; "4", "хор" → 4; "3", "уд" → 3; "2", "неуд" → 2.
  3. Игнорировать (удалить) "неявка", "н", пустые строки и всё, что не попадает в диапазон 2–5.
  4. Вернуть новый список, отсортированный по убыванию.
