🎯 Цикл for: теория

Сначала — теория с примерами, затем — 11 задач, где нужно применить всё это на практике.

📚 Теория: цикл for

1. Что такое цикл for?

Цикл for выполняет один и тот же блок кода несколько раз — по одному разу для каждого элемента в последовательности.

Синтаксис:

for переменная in последовательность:
    действия

Тело цикла обязательно отделяется четырьмя пробелами (отступом). Всё, что написано с отступом, повторяется на каждом шаге.

Пример: вывести три шага обратного отсчёта.

for i in range(3):
    print("Шаг", i)

Вывод:

Шаг 0
Шаг 1
Шаг 2
💡 Переменная цикла (здесь i) на каждом шаге принимает новое значение из последовательности. Имя может быть любым: i, num, ch, step — главное, чтобы оно отражало смысл.

2. Функция range()

range() создаёт последовательность целых чисел. У неё три варианта записи:

  • range(5) → 0, 1, 2, 3, 4 — от 0 до 5, не включая 5.
  • range(2, 6) → 2, 3, 4, 5 — от 2 до 6, не включая 6.
  • range(1, 10, 2) → 1, 3, 5, 7, 9 — с шагом 2.
  • range(5, 0, -1) → 5, 4, 3, 2, 1 — с шагом −1 (обратный порядок).

Правило: правая граница никогда не включается. Чтобы дойти до N включительно, пишите range(N + 1).

Пример: вывести чётные числа от 2 до 10.

for i in range(2, 11, 2):
    print(i)

Вывод:

2
4
6
8
10

Пример: обратный отсчёт от 5 до 1.

for i in range(5, 0, -1):
    print(i)
print("Поехали!")

Вывод:

5
4
3
2
1
Поехали!

3. Перебор строки посимвольно

Строка — это последовательность символов, поэтому for может пройти по каждому символу.

word = "Python"
for letter in word:
    print(letter)

Вывод:

P
y
t
h
o
n

Пример: посчитать количество гласных в слове.

word = "программирование"
count = 0
for ch in word:
    if ch in "аеёиоуыэюя":
        count += 1
print(count)   # 8

Пример: собрать новую строку из символов исходной.

word = "кот"
result = ""
for ch in word:
    result += ch + "-"
print(result)   # к-о-т-
💡 Если нужен индекс символа, а не сам символ, используют for i in range(len(s)): и обращаются к s[i].

4. break и continue

Иногда нужно изменить обычный ход цикла:

  • break — немедленно выйти из цикла.
  • continue — пропустить остаток текущей итерации и перейти к следующей.

Пример с break: найти первое слово до пробела.

text = "привет мир"
result = ""
for ch in text:
    if ch == " ":
        break
    result += ch
print(result)   # привет

Пример с continue: убрать все гласные из слова.

word = "молоко"
result = ""
for ch in word:
    if ch in "аеёиоуыэюя":
        continue
    result += ch
print(result)   # млк
💡 break часто используют, когда ищут первое подходящее значение: как только нашли — дальше перебирать незачем.

5. Вложенные циклы

Цикл можно поместить внутрь другого цикла. Внешний цикл выполняется один раз, а внутренний за это время пробегает все свои значения.

Пример: таблица умножения 3 × 3.

for i in range(1, 4):
    for j in range(1, 4):
        print(i * j, end=" ")
    print()

Вывод:

1 2 3 
2 4 6 
3 6 9

Здесь print(..., end=" ") печатает число и пробел без перевода строки, а пустой print() после внутреннего цикла переводит строку.

Пример: вывести пары (i, j), где j ≤ i.

for i in range(1, 4):
    for j in range(1, i + 1):
        print(i, j)

Вывод:

1 1
2 1
2 2
3 1
3 2
3 3
💡 Вложенные циклы нужны всегда, когда работаем с двумя измерениями: строки и столбцы, позиция и значение, пара чисел.

6. Четыре шаблона: счётчик, сумма, флаг, сборка строки

Почти любая задача на for — это один из четырёх шаблонов или их комбинация.

① Счётчик — сколько раз выполнилось условие.

count = 0
for i in range(1, 21):
    if i % 5 == 0:
        count += 1
print(count)   # 4

② Сумма — накопить общее значение.

n = 4729
total = 0
for ch in str(n):
    total += int(ch)
print(total)   # 22

③ Флаг — проверить, есть ли в данных нужное свойство.

word = "объявление"
found = False
for ch in word:
    if ch == "я":
        found = True
        break
print("YES" if found else "NO")   # YES

④ Сборка строки — постепенно составлять результат.

s = "abc"
result = ""
for ch in s:
    result = ch + result
print(result)   # cba
💡 Прежде чем писать код, ответьте себе: «Мне нужно посчитать, сложить, проверить или собрать?» — и выберите шаблон.

🎯 Задачи

Задание: Получите целое число N. Вычислите сумму всех чисел от 1 до N, которые не делятся на 3 и не оканчиваются на 7. Выведите эту сумму.

Пример для N = 10:

Ввод: 10
Вывод: 30
⚠️ В исходном тексте примера была опечатка: указано 33. Правильная сумма для N = 10 — 30, потому что остаются числа 1, 2, 4, 5, 8, 10 (числа 3, 6, 9 делятся на 3, а 7 оканчивается на 7).
Задание 2: Рамка для портрета

Задание: Получите два целых числа N и M (N, M ≥ 3). Выведите рамку из # размером N × M, внутри которой пробелы.

Пример для N = 4, M = 6:

######

######
Задание 3: Голографическая пирамида

Сюжет. На экране нужно построить голографическую пирамиду для калибровки сканера. Высота пирамиды — N строк. В первой строке одна звезда по центру, в каждой следующей — на две звезды больше.

Задание: Получите целое число N (N ≥ 1). Выведите пирамиду из символов * высотой N строк, выровненную по центру.

Пример для N = 4:

Пример:

Ввод:

Задание 5: Восстановление сжатого текста

Сюжет. Древний алгоритм сжатия заменял повторяющиеся символы парой «символ + количество». Например, AAAABBBCC превращалось в A4B3C2. Но архив повреждён: часть данных сохранилась в сжатом виде, и теперь нужно восстановить исходный текст, чтобы прочитать послание.

Задание: Получите строку в сжатом формате: чередование буквы и числа (число может быть многозначным). Восстановите исходную строку и выведите её.

Пример:

Ввод: A4B3C2
Вывод: AAAABBBCC

Ввод: X12Y1
Вывод: XXXXXXXXXXXXY
Задание 6: Проверка анаграмм

Сюжет. В лингвистическом архиве ищут анаграммы — слова, состоящие из одних и тех же букв в разном порядке. Например, «кот» и «ток». Но в архиве тексты могут содержать пробелы и разный регистр, и нужно сравнивать именно буквы, игнорируя всё остальное.

Задание: Получите две строки. Определите, являются ли они анаграммами: если игнорировать пробелы и регистр, то наборы букв должны совпадать. Выведите YES или NO.

Пример:

Ввод:
Кот
Ток
Вывод: YES

Ввод:
Кот
Кит
Вывод: NO
Задание 7: Электронные часы без повторов

Сюжет. Старинные электронные часы в музее показывают время в формате HH:MM. Хранитель заметил, что иногда все четыре цифры на табло различны — и считает такие моменты «удачными». Сколько таких моментов бывает за сутки?

Задание: Не запрашивайте ввод. Переберите все возможные показания часов от 00:00 до 23:59 с помощью вложенных циклов for и посчитайте, сколько раз все четыре цифры различны. Выведите это количество.

Пример (фрагмент перебора):

00:00 — нет (0 повторяется)
01:23 — да (0,1,2,3 различны)
12:34 — да
23:45 — да
Ответ: 644

Исполнитель Черепаха движется по декартовой плоскости. Базовые команды: Вперёд n — пройти n единиц в направлении головы; Назад n — пройти n единиц в противоположном направлении; Налево m / Направо m — повернуть на m градусов; Поднять хвост / Опустить хвост — переключить режим рисования. Начальное положение — начало координат, направление — вдоль положительного направления оси ординат (или абсцисс — см. условие конкретной задачи).
