Урок #8: Строки и списки в Python

Изучите работу со строками и списками: основные операции, методы обработки данных и практическое применение для решения различных задач.

📚 Теория: Строки и списки в Python

1. Основы работы со строками

Строки в Python — неизменяемые последовательности символов:

text = "Hello World"
print(text[0])      # 'H'
print(text[-1])     # 'd'
print(text[2:7])    # 'llo W'
print(len(text))    # 11

Основные методы строк:

  • .upper(), .lower() - преобразование регистра
  • .strip() - удаление пробелов с обеих сторон
  • .replace(old, new) - замена подстрок
  • .split() - разделение строки на список
  • .join(list) - объединение списка в строку

2. Методы проверки строк

Полезные методы для валидации данных:

text = "Hello123"
print(text.isalpha())    # False (есть цифры)
print(text.isdigit())    # False (есть буквы)
print(text.isalnum())    # True (только буквы и цифры)
print(text.startswith("H"))  # True
  • .isalpha() - только буквы
  • .isdigit() - только цифры
  • .isalnum() - буквы и/или цифры
  • .isspace() - только пробельные символы

3. Работа со списками

Списки — изменяемые последовательности элементов:

my_list = [1, 2, 3, "текст", True]
print(my_list[0])       # 1
print(my_list[-1])      # True
print(my_list[1:3])     # [2, 3]

4. Основные методы списков

Методы для добавления, удаления и изменения элементов:

numbers = [1, 2, 3]
numbers.append(4)       # [1, 2, 3, 4]
numbers.insert(1, 5)    # [1, 5, 2, 3, 4]
numbers.remove(2)       # [1, 5, 3, 4]
popped = numbers.pop()  # 4, список: [1, 5, 3]
  • .append(element) - добавить в конец
  • .insert(index, element) - вставить по индексу
  • .remove(element) - удалить первое вхождение
  • .pop(index) - удалить и вернуть элемент

5. Сортировка и поиск в списках

Методы для упорядочивания и поиска элементов:

numbers = [3, 1, 4, 2]
numbers.sort()          # [1, 2, 3, 4]
numbers.reverse()       # [4, 3, 2, 1]

fruits = ['apple', 'banana', 'cherry']
print(fruits.index('banana'))  # 1
print(fruits.count('apple'))   # 1

6. Преобразование типов

Важные преобразования между строками, числами и списками:

# Строка → число
number = int("123")
float_num = float("3.14")

# Число → строка
text = str(123)

# Строка → список символов
chars = list("hello")  # ['h', 'e', 'l', 'l', 'o']

# Список → строка
words = ['a', 'b', 'c']
result = ''.join(words)  # 'abc'

7. Работа с числами и цифрами

Операции для работы с отдельными цифрами чисел:

number = 123
# Получение цифр
hundreds = number // 100     # 1
tens = (number // 10) % 10   # 2
units = number % 10          # 3

# Преобразование числа в список цифр
digits = [int(d) for d in str(number)]  # [1, 2, 3]

8. Системы счисления

Работа с числами в разных системах счисления:

# Преобразование в двоичную систему
binary = bin(5)        # '0b101'
binary_clean = bin(5)[2:]  # '101'

# Преобразование в другие системы
octal = oct(10)        # '0o12'
hexadecimal = hex(255) # '0xff'

# Преобразование из любой системы в десятичную
decimal = int('101', 2)    # 5
decimal = int('12', 8)     # 10
decimal = int('ff', 16)    # 255

Автомат получает на вход трёхзначное число. По этому числу строится новое число по следующим правилам:

  1. Перемножаются первая и вторая, а также вторая и третья цифры.

Задание 4: Двоичный алгоритм (превышает 43)

На вход алгоритма подаётся натуральное число N. Алгоритм строит по нему новое число R следующим образом:

  1. Строится двоичная запись числа N.
  2. К этой записи дописываются справа ещё два разряда по следующему правилу:
    • Складываются все цифры двоичной записи, и остаток от деления суммы на 2 дописывается в конец числа (справа).
    • Над этой записью производятся те же действия — справа дописывается остаток от деления суммы цифр на 2.

Полученная запись является двоичной записью искомого числа R.

Задача: Укажите минимальное число R, которое превышает 43 и может являться результатом работы алгоритма. В ответе это число запишите в десятичной системе.

Задание 8: Чек из магазина

Задание 10: Виселица — часть 2. Логика игры

Теперь добавьте саму игру: игрок угадывает буквы по одной.

Что сделать:

  8. Игра заканчивается при угадывании всех букв (победа) или когда wrong == 6 (поражение) — показать последний кадр виселицы и загаданное слово.
