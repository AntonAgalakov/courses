Урок #1: Основы Python

В этом уроке вы познакомитесь с базовыми понятиями языка Python: переменные, типы данных, ввод и вывод.

📚 Основные понятия

Переменная — это именованный объект в программе, который хранит некоторое значение. Это значение может быть числом, строкой, символом (в том числе эмодзи), логическим значением и другими типами данных.

Пример: name = "Алиса", age = 15

Типы данных — определяют, какие значения может принимать переменная и какие операции можно над ней выполнять.

  • str — строка (текст): "Привет"
  • int — целое число: 42
  • float — дробное число: 3.14
  • bool — логическое значение: True или False

Функции ввода и вывода:

  • print(...) — выводит текст или значение на экран.
  • input(...) — запрашивает у пользователя ввод с клавиатуры. Всегда возвращает строку!

Пример:
name = input("Как вас зовут? ")
print("Привет,", name)

Полезные функции и операторы:

  • len(s) — длина строки: len("Python") → 6
  • + - * / — арифметика, // — целочисленное деление, % — остаток, ** — степень
  • ==, !=, <, > — сравнения. Возвращают True или False: 5 > 3 → True

💡 Советы по решению задач

  • Всегда проверяйте, какой тип данных вы получаете от input() — если нужно число, используйте int() или float().
  • Для вывода нескольких значений в print() можно перечислять их через запятую: print("Вам", age, "лет").

Пример: Простая анкета

name = input("Как вас зовут? ")
age = input("Сколько вам лет? ")
print("Привет,", name + "! Вам", age, "лет.")

Библиотека rich — цветной вывод

Обычный print() выводит чёрно-белый текст. Библиотека rich делает вывод цветным и красивым. Работает на Linux, macOS и Windows.

Установка (один раз в терминале):

pip install rich

Подключение в начале программы:

from rich import print

После этого тот же самый print() начинает понимать специальные метки в квадратных скобках:

print("[bold red]Ошибка![/bold red] Что-то пошло не так")
print("[green]✓ Всё хорошо[/green]")
print("[blue on white] Синий текст на белом фоне [/blue on white]")

Основные цвета: red, green, yellow, blue, magenta, cyan, white, black.

Стили: bold (жирный), italic (курсив), underline (подчёркнутый), dim (тусклый).

Фон: добавляется словом on: [white on blue].

Комбинировать можно через пробел: [bold yellow on blue].

💡 Метка действует до конца строки или до закрывающего тега [/...]. Цвета отлично сочетаются с эмодзи! А если вывод перенаправить в файл, rich сам отключит цвета.

🎯 Задачи

Задача 1. Анкета

Программа по очереди спрашивает у пользователя:

  • имя,
  • фамилию,
  • любимый фильм.

Используй input() с подсказкой, например:

name = input("Как тебя зовут? ")

Затем выведи текст:

Привет, меня зовут <имя> <фамилия>.
Мой любимый фильм — <фильм>.

Пример:

Ввод:
Иван
Петров
Титаник

Вывод:
Привет, меня зовут Иван Петров.
Мой любимый фильм — Титаник.

Задача 2. Перестановка цифр

Дано двузначное число (от 10 до 99). Поменяй его цифры местами.

Подсказка:

n = int(input("Введите двузначное число: "))

Пример: 34 → 43.

Пример выполнения:

Ввод: 34
Вывод: Новое число: 43

Задача 3. Вес посылки

Сувенир весит 75 г, безделушка — 112 г.

Программа спрашивает, сколько сувениров и сколько безделушек, и выводит общий вес в граммах и в килограммах.

Ровно две строки:

Вес посылки: <N> г
Это <N/1000> кг

Используй input() с подсказкой:

souvenirs = int(input("Сколько сувениров? "))
trinkets = int(input("Сколько безделушек? "))

Пример:

Ввод:
3
5

Вывод:
Вес посылки: 785 г
Это 0.785 кг

Задача 4. Пингвины 🏋️‍♂️

Нарисуй трёх пингвинов с помощью print() и умножения строк.

Совет: одну строку пингвина можно нарисовать так:

print("   _~_    " * 3)

Пробелы в конце строк не важны — сравнение их игнорирует. Ничего читать из input() не нужно, только напечатай картинку.

Пример:

   _~_       _~_       _~_    
  (o o)     (o o)     (o o)   
 /  V  \   /  V  \   /  V  \  
/(  _  )\ /(  _  )\ /(  _  )\ 
  ^^ ^^     ^^ ^^     ^^ ^^

Задача 5. Сколько пицц заказать

В одной пицце 8 кусков. Каждый гость съест 3 куска.

Программа спрашивает, сколько гостей придёт, и выводит:

Нужно кусков: <всего>
Целых пицц: <сколько целых пицц>
Ещё кусков: <сколько кусков сверх целых пицц>

Используй input() с подсказкой:

guests = int(input("Сколько гостей? "))

Пример:

Ввод: 5

Вывод:
Нужно кусков: 15
Целых пицц: 1
Ещё кусков: 7

Задача 6. Секунды 🕐

Пользователь вводит количество секунд. Программа переводит их в часы, минуты и секунды.

Пример:

Ввод:
3672

Вывод:
1 ч 1 мин 12 сек

Задача 7. Сколько лет собаке 🐶

Считается, что 1 год собаки ≈ 7 человеческих лет, но только для первых двух лет жизни (после — старение замедляется).

Упрощённая формула:

  • первые 2 года: 2 * 10.5 человеческих лет,
  • каждый следующий год: + 4 человеческих года.

Спроси возраст собаки (можно дробный) и выведи её «человеческий» возраст.

Пример:

Ввод: 3

Вывод:
Собаке 3 года — это 25.0 человеческих лет.

Задача 8. Зерно на шахматной доске ♟️

На первую клетку кладут 1 зерно, на вторую — 2, на третью — 4, на каждую следующую — вдвое больше. Спроси номер клетки (1–64) и выведи, сколько зёрен на ней.

Пример:

Ввод: 5
Вывод: На 5-й клетке 16 зёрен.

Задача 9. Экран загрузки ⚙️

Программа ничего не спрашивает. Выведи строки, имитирующие загрузку программы:

[bold cyan]Загрузка...[/bold cyan]
[yellow]░░░░░░░░░░  20%[/yellow]
[yellow]█████░░░░░  50%[/yellow]
[green]█████████░  90%[/green]
[bold green]✓ Готово![/bold green]

Попробуй сделать так, чтобы каждая строка прогресса была своего цвета: чем больше заполнено — тем «теплее» цвет. Подсказка по цветам: red, yellow, green, cyan.

🎲 Задача 10. Угадай число ⭐

Компьютер загадывает случайное число от 1 до 100. Пользователь пытается его угадать. После каждой попытки программа подсказывает: «больше» или «меньше». Когда число угадано — поздравление и количество попыток.

Пример работы:

Я загадал число от 1 до 100. Попробуй угадать!

Твоя догадка: 50
⬆ Моё число больше!

Твоя догадка: 75
⬇ Моё число меньше!

Твоя догадка: 63
🎉 Угадал! Ты справился за 3 попытки!
