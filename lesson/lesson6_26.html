Урок #6: Строки в Python

Освойте продвинутые методы работы со строками: фильтрация, кодирование, баланс скобок и многое другое. От простых манипуляций до сложных алгоритмов — всё начинается со строк!

📚 Строки в Python: полное руководство

1. Что такое строка?

Строка — это упорядоченная неизменяемая последовательность символов, заключённая в кавычки:

s = "Привет"
t = 'Мир'

Строки могут содержать буквы, цифры, знаки препинания, пробелы и спецсимволы.

В Python строки — неизменяемые: любая «модификация» создаёт новую строку.

2. Индексы и срезы

Каждый символ в строке имеет индекс (с 0):

word = "Python"
print(word[0])  # 'P'
print(word[-1]) # 'n' (последний)

Срезы — извлечение части строки:

word[1:4]  # 'yth'
word[:3]   # 'Pyt'
word[3:]   # 'hon'
word[::-1] # 'nohtyP' (реверс)

3. Полезные методы строк

Python предоставляет десятки методов для работы со строками:

  • .upper(), .lower() — регистр
  • .strip() — убрать пробелы по краям
  • .replace(old, new) — замена
  • .split() — разбить на список
  • .join(list) — собрать из списка
  • .find(), .index() — поиск
  • .count(sub) — подсчёт вхождений
text = "  Привет, Мир!  "
print(text.strip().upper())  # "ПРИВЕТ, МИР!"

4. Проверка содержимого

Методы для проверки типа содержимого:

  • .isdigit() — только цифры?
  • .isalpha() — только буквы?
  • .isalnum() — буквы и/или цифры?
  • .isspace() — только пробелы?
  • .startswith(pref), .endswith(suff)
"123".isdigit()    # True
"Hello".isalpha()  # True
"Hello123".isalnum() # True

5. Форматирование строк

Способы вставки переменных в строку:

1. f-строки (рекомендуется):

name = "Алиса"
age = 30
print(f"Меня зовут {name}, мне {age} лет.")

🎯 Задачи по теме «Строки»

Задачи расположены по возрастанию сложности: от простых операций со строками до олимпиадных и практических. Решайте по порядку — каждая следующая опирается на предыдущие.

Задание 1: Цифровой фильтр

Напишите программу, которая получает на вход строку и удаляет из нее все цифры (символы от '0' до '9'). Все остальные символы (буквы, знаки препинания, пробелы) должны остаться на своих местах в исходном порядке.

Примеры:

Вход: "Hello123 World456!" → Выход: "Hello World!"

Вход: "Мой номер: +7 (123) 456-78-90" → Выход: "Мой номер: + () --"

Задание 2: Великий Переводчик на 'Питонячий' Язык

Реализуйте программу, которая преобразует слова по специальному правилу: после каждой гласной буквы русского алфавита (а, е, ё, и, о, у, ы, э, ю, я) вставляется слог, состоящий из буквы "с" и этой же гласной.

Примеры:

Вход: "привет" → Выход: "присивесет"

Вход: "мама" → Выход: "масамаса"

Вход: "Хорошо" → Выход: "Хосорошосо"

Задание 3: Найди лишний символ

Дана строка, в которой ровно один символ встречается нечетное число раз, а все остальные символы — четное количество раз. Найдите этот "лишний" символ.

Примеры:

Вход: "aabbc" → Выход: 'c'

Вход: "1122334" → Выход: '4'

Задание 4: Строки-друзья

Две строки одинаковой длины считаются "друзьями", если одну из них можно превратить в другую, изменив ровно один символ. Напишите программу, которая принимает две строки и возвращает True, если они являются "друзьями", и False — в противном случае.

Примеры:

Вход: "abc", "axc" → Выход: True

Вход: "hello", "hallo" → Выход: True

Вход: "python", "python" → Выход: False

Задание 5: Палиндром по-настоящему

Строка считается палиндромом, если читается одинаково слева направо и справа налево. Проверьте, является ли строка палиндромом, игнорируя регистр букв, пробелы и знаки препинания.

Примеры:

Вход: "А роза упала на лапу Азора" → Выход: True

Вход: "Я иду с мечем, судия" → Выход: True

Вход: "Привет, мир" → Выход: False

Вход: "" → Выход: True

Подсказка: оставьте только буквы в нижнем регистре, затем сравните строку с её реверсом.

Задание 6: camelCase ↔ snake_case

Реализуйте преобразование идентификаторов между двумя популярными стилями именования.

  • J1. camelCase → snake_case: каждая заглавная буква (кроме первой позиции) начинает новое слово.
  • J2. snake_case → camelCase: первое слово с маленькой буквы, остальные — с заглавной.
  • J3. Для произвольного идентификатора определите его стиль и количество слов.

Примеры:

Вход: "saveChangesInTheEditor" → Выход: "save_changes_in_the_editor" (5 слов, camelCase)

Вход: "my_variable_name" → Выход: "myVariableName" (3 слова, snake_case)

Вход: "PascalCase" → Выход: "pascal_case" (2 слова, PascalCase)

Вход: "my-var-name" → Выход: kebab-case

Задание 7: Сломанная раскладка

Знакомая ситуация: печатаешь быстро, а в чате вместо "привет" появляется "ghbdtn". Клавиатура была в английской раскладке, а вы набирали русский текст. Напишите программу, которая «починит» текст — переведёт английские буквы в русские по расположению клавиш на клавиатуре.

Примеры:

Вход: "ghbdtn" → Выход: "привет"

Вход: "Vbh" → Выход: "Мир"

Вход: "rjynhjkm" → Выход: "контроль"

Вход: "Ghtptynfwbz" → Выход: "Презентация"

Подсказка: используйте dict, где ключи — английские буквы, значения — соответствующие русские. Заглавные буквы обрабатывайте отдельно (или через .lower() + .upper()).

Вопросы на подумать:

  • А как быть с русской буквой ё? Она живёт на клавише ` (тильда) — не забудьте её в словаре.
  • А что делать со знаками препинания? В русской раскладке , — это shift + ?, а . — это ю… Всё сложно.
  • А если в тексте правда есть английские слова? Как отличить «сломанный» текст от «настоящего английского»?
Задание 8: Проверка скобочного баланса

Напишите программу, которая проверяет, правильно ли расставлены скобки в строке-формуле. Учитывайте не только парность скобок, но и их порядок (открывающая должна идти перед закрывающей). Рассматривайте скобки трех видов: круглые ( ), квадратные [ ] и фигурные { }.

Примеры:

Вход: "(a + [b * {c - d}])" → Выход: True

Вход: "[(])" → Выход: False

Вход: "({[}])" → Выход: False

Задание 9: Римские числа

Реализуйте перевод между арабскими и римскими числами. Римские цифры: I = 1, V = 5, X = 10, L = 50, C = 100, D = 500, M = 1000. Вычитающие пары: IV = 4, IX = 9, XL = 40, XC = 90, CD = 400, CM = 900.

  • D1. Переведите число от 1 до 3999 в римскую запись.
  • D2. Обратное преобразование: римская запись → число.
  • D3. Найдите сумму двух римских чисел и верните её в римской записи.

Примеры:

Вход: 1994 → Выход: "MCMXCIV"

Вход: "MCMXCIV" → Выход: 1994

Вход: "XIV", "VI" → Выход: "XX"

Задание 10: Длиннейшая подстрока без повторов

Найдите самую длинную подстроку, в которой все символы различны.

  • A1. Найдите длину такой подстроки.
  • A2. Верните саму подстроку (не только длину).
  • A3. Найдите все максимальные подстроки без повторов (если их несколько).

Примеры:

Вход: "abcabcbb" → Выход: 3 (подстрока "abc")

Вход: "bbbbb" → Выход: 1 (подстрока "b")

Вход: "pwwkew" → Выход: 3 (подстрока "wke")

Вход: "" → Выход: 0

Подсказка: используйте dict для хранения последней позиции каждого символа и «скользящее окно» (два указателя left и right). Наивное решение за O(n²) легко написать — попробуйте сделать за O(n).

Для найденного x вычислите частное от деления значения арифметического выражения на 21 и укажите его в ответе в десятичной системе счисления. Основание системы счисления указывать не нужно.
